# 버섯 동굴 배치·광맥량 조정

2026-10-04 사용자 전달 기획 수정이 기존 CSV의 버섯 광맥 규칙보다 우선한다.

- 느타리·표고·석이는 새 월드에서 광맥으로 배치하지 않는다. 기존 지층/경도/채굴·드롭 규칙은 유지한다.
- 최종 지형의 지하 공기 연결 구역을 한 번 순회하고, 같은 동굴의 가까운 바닥에 버섯 2~3개를 개별 배치한다. 각 버섯은 해당 지층의 종류를 사용한다.
- 바닥과 위쪽 여유 공간이 있는 후보만 사용한다. 상자 자리·제단·얼음호수는 피하고 서로 붙은 광맥 형태를 만들지 않는다. 적합한 자리가 2개 미만이면 그 동굴은 건너뛴다.
- 동굴을 추가로 파거나 캣닢·상자 생성/수확 규칙을 바꾸지 않는다. 연결된 하나의 큰 동굴도 한 구역으로 취급한다.
- 광맥 생성 횟수 산식과 원래 무작위 보행은 유지한다. 배치하는 보행 수만 평균 85%로 줄이고, 정수 수량은 확률 반올림한다. 예: 3칸은 평균 2.55칸, 6칸은 평균 5.1칸. 광맥 하나는 최소 1칸을 유지한다.
- 기존 버섯 프로파일은 지층·경도 조회와 구버전 월드 복원에 필요하므로 삭제하지 않는다.

## 저장 영향

- SaveGame에 `resourceGenerationVersion` 한 필드를 추가했다. 기존 JSON에서 필드가 없으면 0이다.
- 버전 0은 기존 광맥량·버섯 광맥 규칙 그대로 재생성한다. 새 월드는 버전 1로 저장하고 새 규칙으로 복원한다.
- 기존 저장을 삭제하거나 이미 생성된 월드를 자동 변환하지 않는다. 변경된 분포를 확인하려면 새 게임으로 시작해야 한다.
- A 월드 생성/세션과 공용 저장 버전 필드만 변경했다. B 전투·스폰 로직은 수정하지 않았다.

## 검증

- 런타임 C#와 에디터 C# 순차 컴파일: 오류 0개. 기존 경고는 남아 있다.
- 코드 흐름에서 구버전 생성 분기, 생성/저장/복원 버전 전달, 동굴 후보 조건과 개수 제한을 확인했다.
- Unity MCP 세션 응답 확인. Unity·게임 실행, 플레이 모드, GPU 검증은 수행하지 않았다.
- 실제 월드 분포·생성 시간·저장 후 이어하기는 런타임 미검증이다. 광맥 중복/후처리로 최종 블록 수의 감소율은 정확히 15%가 아닐 수 있다.
