# 부채 F 판정 확정 반영

2026-10-05 사용자 전달 기획자 직접 확정을 우선 적용한다. 이전 v86의 철선·설풍선 F 넉백 2칸 및 상위 부채 F 미명시보다 최신 규칙이다.

- 일반 공격은 기존 프로필의 사거리·넉백·최대 대상 수를 사용한다.
- 일반 공격이 있는 부채의 F 사거리 = 기본 프로필 사거리 + 2칸.
- 일반 공격이 있는 부채의 F 넉백 거리 = 기본 프로필 넉백 거리 + 2칸.
- F는 공격 방향의 기존 부채꼴 각도와 사거리 안에서 가장 가까운 살아 있는 적 1체만 타격한다. 거리는 공격 원점부터 피격 콜라이더의 가장 가까운 지점까지 측정한다. 자기 자신·사망 개체를 제외하고 여러 콜라이더를 가진 개체도 Health 기준으로 중복 처리하지 않는다.
- 얼음뿌리 채찍선은 끌어당김 방향을 유지한다. 합죽선은 일반 공격이 없으므로 +2 규칙에서 제외하고 기존 F 사거리 2칸·넉백 2칸으로 롤백한다.
- F 바람 이펙트 끝도 증가한 F 사거리 끝에 맞춘다. 추가 요청으로 부채 넉백 시간 배율은 1로 롤백하여 기본 0.24초를 사용한다(이전 0.36초). 일반 공격과 F 모두 적용하며 넉백 거리는 유지한다. 바람 프레임 간격 0.15초는 유지한다.
- 추가 요청: 일반 공격에도 같은 바람 이펙트를 표시한다. 일반은 기본 사거리, F는 각 부채의 F 사거리를 전달하여 각 공격 사거리 끝과 이펙트 끝을 맞춘다. 합죽선의 일반 공격 없음은 유지하며 이펙트에서 추가 피해를 발생시키지 않는다.

|---|---|---|---|---|---|
| 철선·설풍선·서리 부채 | 2칸 | 4칸 | 밀치기 1.5칸 | 밀치기 3.5칸 | 1 / 1 |
| 얼음뿌리 채찍선 | 4칸 | 6칸 | 끌어당기기 1.5칸 | 끌어당기기 3.5칸 | 1 / 1 |
| 한파 부채 | 3칸 | 5칸 | 밀치기 2칸 | 밀치기 4칸 | 3 / 1 |
| 합죽선 | 일반 공격 없음 | 2칸 | 일반 공격 없음 | 밀치기 2칸 | 없음 / 1 |

## 검증

- CPU C# 컴파일: Assembly-CSharp 오류 0 / 경고 3, Assembly-CSharp-Editor 오류 0 / 경고 38.
- Unity MCP 콘솔 오류 조회: 0건。
- 정적 흐름 검토: F 전용 StrikeFanAbility → 거리순 후보 → 범위·각도·생존 필터 → 1체 타격. 일반 공격에는 거리 정렬과 F 사거리 확장을 적용하지 않는다.
- Unity/게임 실행 및 런타임 물리·시각 검증은 수행하지 않았다.
