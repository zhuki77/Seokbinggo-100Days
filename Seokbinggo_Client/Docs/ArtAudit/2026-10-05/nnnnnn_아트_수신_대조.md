## 5. 실제 확인과 한계

- Aseprite 34개, 총 43프레임의 헤더·프레임·셀·태그를 직접 파싱했다. RGBA 그림을 CPU로 합성해 미리보기에서 전부 확인했다.
- [34종 전체 미리보기](nnnnnn_수신_34종_미리보기.png), [프레임/셀/태그 구조 기록](nnnnnn_원본_구조.json).
- 일부 파일의 명명만으로 용도를 확정하지 않았다. 변형 선택·대응 ID 확인이 필요한 항목은 별도로 표시했다.
- MCP로 기존 프로젝트와 비플레이 상태를 확인했다. 3종을 임포터로 설정하고 참조 경로를 재조회했다. Sprite는 원본 불투명 영역대로 장독 창고 14×16, 얼음 항아리 13×16, 저체온 16×16이며 투명 여백만 제외됐다. 원본 3종은 ZIP 파일과 SHA-256이 일치한다.
- CPU 기반 C# 런타임→에디터 프로젝트를 순차 컴파일했다. 런타임 오류 0/경고 3, 에디터 오류 0/경고 38. 이 검증은 런타임 표시 검증이 아니다.
- 인게임 표시·런타임 동작은 미검증이다. Unity/게임 신규 실행, 플레이 모드, GPU 검증 없음.
