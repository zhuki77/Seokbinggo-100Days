## 2. 다시 발주하지 않을 기존 납품 항목

- 버섯 3종: 전용 인벤 아이콘과 월드 타일이 모두 연결되어 있다. 느타리·표고 월드 PNG는 10-4 납품 원본에서 추출한 그림이며 임의 제작이 아니다.
- 부적 5종, 이정표 부적 건물, 첫서리 발톱·백중 보따리·여의주 발톱: 전용 참조 있음.
- 대장간, 물단지, 진화 터렛·유틸 설치물·서리 금줄: 현재 건물 참조 있음. 미장이 인형의 전체 월드 원본을 아이콘으로 쓰는 방식은 사용자 확정이다.
- v84.1 문서에서 추출한 아이템 ID와 일치하는 현재 아이콘 참조 63개를 재확인: fileID 0 또는 원본 메타 GUID 미식별 항목 0개. 이 수는 문서 본문의 ‘63종’ 집계 단위와 별개인 **아이콘 ID 대조 수**다.
- 해당 원본의 납품 사실과 현재 카탈로그 참조를 확인한 것이며, 발주 외관·프레임·착용 상태까지 모두 합격하거나 실제 플레이 검수가 끝났다는 의미는 아니다. 최신 원본에 사용자가 승인한 1프레임/재사용 방식을 구문서의 2프레임 요구로 임의 되돌리지 않는다.

## 5. 신규 발주와 구분할 재사용 UI 연결

v86의 `ui_freeze_x2`, `ui_temp_gauge`, `ui_scroll_frame`/`ui_tooltip`, `ui_result_bg` 등은 기존 재사용 대상으로 쓰여 있다. 현재 프로젝트의 파일명·카탈로그 필드가 문서 이름과 달라 정확한 대응 확인이 필요하다. 문서명 파일이 없다는 이유만으로 미납을 확정하거나 새로 그려 달라고 요청하지 않는다.

S3의 현재 ❄ 표시는 글리프, 온도 막대와 결과 바탕은 코드 도형이다. 발주서가 지정한 기존 아트를 모두 적용한 상태로 표현하지 않는다. 대응 원본이 확인되면 개발 연결 범위다.

검증: 파일 목록·문서·직렬화 카탈로그 참조·원본 GUID 대조. Unity MCP 도구 미노출로 이번에 실제 Sprite 객체 응답을 확인하지 못했고, 게임/Unity 실행·플레이 모드 검증도 수행하지 않았다. 코드나 카탈로그는 이번 조사에서 수정하지 않았다.
