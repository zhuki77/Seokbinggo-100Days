# 잡몹 스폰 금지 HUD 아이콘 교체

사용자가 기획자 직접 컨펌으로 전달한 변경: 해시계의 빗장을 `D:/다운로드/잡몹X_icon.aseprite`로 교체하고 체력 HUD 근처에 표시한다. 이 전달을 이전 해시계 빗장 배치보다 우선한다.

- 원본: RGBA 16×16px, 1프레임, 100ms. 셀 및 불투명 영역 16×16px. 다른 그림으로 대체하거나 그림을 수정하지 않았다.
- 게임 원본: `Assets/Art/Gameplay/night_spawn_blocked_icon.aseprite`.
- 기존 Unity 에디터의 Aseprite 임포터로 Sprite/PPU 16/Point/Clamp/밉맵 없음 설정. 메타데이터는 직접 편집하지 않았다.
- 실제 임포트 Sprite의 GUID와 fileID를 MCP로 조회해 `GameplayArtCatalog.nightSpawnBlockedIcon`에 기록했다. 현재 사용자 플레이 모드로 새 C# 필드가 에디터에 컴파일되지 않아, 해당 참조 한 줄은 카탈로그 파일에 직접 추가했다. Sprite 메타데이터 변경과는 별개다.
- 후속 사용자 요청에 따라 보스 전투·저체온 아이콘 모두 HUD 기준 12×12로 확대했다. HUD 오른쪽에서 2px 간격을 두고 같은 왼쪽 선에 배치한다. 최종 첨부 위치에 맞춰 보스 아이콘은 HUD 상단에서 3px 아래, 저체온 아이콘은 HUD 하단에서 3px 위로 여백을 둔다. 수치는 Canvas 기준이며 화면에서는 기존 HUD 배율을 따른다. 저체온 아이콘 확대/축소 효과는 제거하고 고정 크기를 사용한다. 주변 배치·색상·체력/온도 표시를 유지한다.
- 기존 `NightSpawnLock` 씬 참조는 보존하고 비활성화한다. 해시계에서 빗장을 다시 켜던 코드만 제거했다. 씬/프리팹은 수정하지 않았다.
- 기존 조건 `밤 && (보스 활성 || 백중 조우 활성)`을 유지한다. 해시계 그림의 활성 여부는 새 상태 아이콘의 표시 조건에서 제외했다. 몬스터 생성·전투·저장 데이터는 변경하지 않았다.
- 실제 연결 검증: MCP 원본 임포트/16×16 Sprite/식별자 확인, 디스크 카탈로그 참조 및 HUD 코드 경로 정적 대조.
- 원본과 프로젝트 파일의 SHA-256 일치. CPU C# 런타임→에디터 순차 컴파일: 오류 각 0개, 경고 3/38개. 변경 파일의 `git diff --check` 통과.
- 플레이 중 HUD 표시·종료/새벽 시 숨김·저체온 동시 표시의 실제 화면은 미검증. 플레이 모드를 시작/종료하거나 게임을 실행하지 않았다. 에디터가 새 코드를 반영한 후 사용자가 확인할 항목이다.
