기존 미제공 요청 7종 중 창고 봉인·목표 화살표·빠진 경계 마커·고친 칸 체크·요괴 피해 아이콘의 대응 자료가 제공되었다. 변형안을 포함하여 총 파일 10개이며 화상 전용 아이콘은 추가 납품이다.

이번 ZIP에서 미확인: 밀폐 성공 코어 서리 파동, 백중날 객귀 체력 프레임. 찬바람 새는 이펙트는 파일명 및 그림 기준 누출 연출이며, 코어에서 퍼지는 밀폐 성공 파동으로 임의 간주하지 않는다.

연결 시 체크 색 2안·피해 실루엣 2안을 선택해야 한다. 경계 누출 원본은 정적 아이콘/정적 마커/6프레임 효과를 구분하여 연결한다. 기존 발주서의 마커 2프레임과 실제 납품(정적 마커·6프레임 이펙트)은 다르므로 납품 구조를 그대로 기록한다.

게임·Unity 실행 및 GPU 검증 없음. 이번에 저장한 PNG는 원본 확인용 CPU 디코딩 미리보기이며 게임 아트를 대체하지 않는다.
