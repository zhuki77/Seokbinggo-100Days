# 설치 미리보기 월드 아트 전수 대조

2026-10-06 사용자 요청: 아이템 아이콘과 실제 설치 모습이 다르면 미리보기는 실제 설치 모습을 사용한다.

## 조사 범위 및 결과

- `TileService.PlacementHardness` 전체 18개 키 중 내부 전용 `door_top`을 제외한 설치 가능 전경 17종을 Unity MCP로 대조했다. 각 월드 아트 연결이 존재한다.
- 아이템 카탈로그의 전체 항목과 건물 카탈로그의 전체 항목을 순회하여 두 설치 경로를 비교했다. 전경은 아이템 아이콘을 조회하여 문제가 있었고, 별도 설치물은 `MainGameTurretRuntime`와 `MainGameEnvironmentState` 모두 같은 BuildingArtCatalog 아트를 사용한다.
- 벽지는 카탈로그 아이콘 대신 실제 설치 시 사용하는 깊이별 배경 타일을 조회해야 한다.

| 전경 ID | 수정 전 조사 결과 | 수정 후 |
|---|---|---|
| door | 별도 인벤토리 아이콘을 사용 | 월드에 등록된 닫힘 문 프레임 사용, 1×2 크기 유지 |
| clay | Items/clay와 Tiles/clay 아트가 다름 | Tiles/clay 사용 |
| ruin_wall, stone_deep | 해당 ID의 아이콘이 없어 더미 미리보기로 대체 | 연결된 실제 월드 타일 사용 |
| rope, dirt, coal, stone, stone_mid, iron_ore, copper_ore, ice_shard, icesteel_ore, frost_essence, insul_wall, roof, iron_insul_wall | 아이콘과 월드 아트가 동일 | 월드 타일을 직접 조회하여 일관성 유지 |
| wallpaper | 아이콘 고정으로 실제 깊이별 배경과 다를 수 있음 | 커서 행의 실제 배경 타일 사용 |

별도 설치물 전수 확인: workbench, furnace, blast_furnace, smithy, arrow_supply, gong_tower, scarecrow, tal_waypoint, water_jar, frost_bell_rope, seonge_tower, cold_wave_tower, ice_trap, ice_anvil, lantern, frost_lantern, saekdong_lantern, sieve, iron_sieve, haetae_statue, nest_bed, magpie_nest, bell_rope, iron_bell_rope, jangdok, ice_core, cold_device, chest, dokkaebi_fire_tower, singijeon_cart, ice_root_battery, cold_wave_battery, plaster_doll, ice_crystal_cooler, cold_wave_core, ice_jar, straw_insul, clay_plaster, munpungji, minhwa_scroll, onggi_pot, wind_chime, saekdong_cushion, jukbuin, daebal. 아이콘이 다른 설치물도 기존 미리보기는 월드용 건물 아트의 기본 프레임을 사용하므로 추가 교체는 필요하지 않다. 건물 카탈로그의 wallpaper 항목은 별도 설치물이 아닌 배경 타일 설치 경로로 처리된다.

## 구현 및 검증

- `TileService.ResolvePlacementPreviewSprite`는 실제 월드 렌더러에 등록된 Tile.sprite를 조회한다. 문은 월드 초기화 시 등록된 닫힘 프레임을 그대로 사용한다. 벽지는 `TryGetWallpaperTileBase`로 깊이별 타일을 선택한다. 현재 연결된 타일은 모두 Unity Tile 형식이다.
- 전경 미리보기는 시작 및 커서 셀 갱신 시 이 조회를 사용한다. 인벤토리 아이콘은 변경하지 않으며 셀 하단 정렬, 설치 유효성 색상, 충돌·밀폐·아이템 소비 판정은 유지한다.
- 정적 코드 흐름과 Unity MCP의 에셋 참조 대조로 검증한다. Unity/게임 실행 및 GPU 검증은 하지 않는다.
