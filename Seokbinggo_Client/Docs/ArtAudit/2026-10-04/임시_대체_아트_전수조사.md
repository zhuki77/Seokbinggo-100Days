# 다른 대상 그림 대체 전수조사 및 정리 — 2026-10-04

> **10-4 납품 적용 후 최신 상태:** 아래는 적용 전 조사 이력이다. 현재 아이콘 154/170종 연결, 16종 미제공이며 설치물 50종 모두 연결했다. 미장이 인형 전체를 아이콘으로 공유한다. [최신 적용 결과](10-4_아트_적용_결과.md)를 기준으로 한다.

본선.zip을 최신 확정 원본으로 삼고 현재 체크아웃의 CSV, Item SO, 여섯 아트 카탈로그, MainGame 씬, 연결 도구와 런타임 표시 코드를 대조했다. 사용자 승인에 따라 다른 대상의 그림은 해제하고 실제 원본이 없는 항목은 미제공으로 분류했다.

## 결과

- 아이템 CSV 165종에 생성 부적 5종을 합친 Item SO 170종을 대조했다. 현재 게임 아이콘 연결 144종, 미제공 26종이다. 카탈로그에는 현재 Item SO가 없는 기존 drought_talisman·stone_mid 보조 항목 2개도 남아 있다.
- 잘못된 아이콘 20종 중 18종은 해제, 2종은 같은 대상의 납품 재료 그림으로 수정했다.
- Unity MCP로 Sprite 필드 562개를 조회했다. 의도적으로 비운 아이콘 필드 18개를 제외한 544개 참조는 정상 해석된다. 나머지 미제공 아이콘 8종은 카탈로그 항목 자체가 없다.
- 재연결 도구의 잘못된 무기 원본 6종을 수정하고, 누락 아이콘 18종을 다시 잘못 연결하지 않게 처리했다.
- 자원 타일의 다른 자원 그림 대체 6종을 비활성화했다. 느타리·표고·얼음뿌리는 같은 대상 납품 원본으로 Tile 에셋을 만들고 씬에 연결했다.
- 설치물 6종과 성에 광석 아이콘 1종을 보완했다. 설치물 카탈로그는 41→47종이며 기존 41개 항목은 유지했다.

## 대체 그림으로 분류하지 않은 항목

- 먹선 경계 5형은 선택적인 레거시 외곽선 오버레이다. 현재 MainGame 씬의 `edgeOverlayTilemap`이 비어 있으므로 코드 생성 먹선도 사용하지 않는다. 이를 현재 월드 아트 부족으로 넣었던 이전 설명은 정정하며, 필수 납품 요청에서 제외한다.
- 벽지는 같은 배경벽 그림을 지층에 맞춰 사용한다.
- 강철/강철 보스, 나무 변형, 부위별 캐릭터 그림은 같은 대상의 시각 변형이다. 최신 납품 변형의 대응이 아직 확정되지 않은 항목은 기존 최신 반영상태 CSV에 별도 기재했다.
- 채굴 타깃 강조, 체력바, 사망 페이드, 경계/콜라이더 전용 투명 Sprite는 기능용 도형이며 아이템 대체 그림이 아니다.
- 채굴 크리티컬·파괴 효과에는 코드 생성 입자가 남는다. 카탈로그의 전용 효과 프레임과 함께 쓰는 장식 입자이며 다른 대상 그림을 빌리지 않는다.
- 플레이어·일반 요괴·나무 등의 공통 사각형 안전 경로는 코드에 남아 있지만 현재 카탈로그에는 해당 대상 아트가 연결되어 있다. 일반 요괴 CSV ID는 전부 캐릭터 카탈로그에 존재한다.
- 플레이어 낙하·착지 등 원본 애니메이션 미제공은 같은 캐릭터의 프레임 부족이며 별도 대상 그림 사용과 구분한다.

## 검증 및 영향

- Unity MCP 에디터 조회/에셋 저장: 6개 카탈로그 562개 Sprite 필드의 참조 상태 확인. 게임·플레이 모드는 실행하지 않았다.
- 적용된 납품 원본 154개 전체의 SHA256이 최신 반영상태 CSV와 일치한다.
- 새 타일 3개의 바이트는 같은 대상 납품 아이콘 원본과 일치하고, 이정표 월드 원본은 ZIP 바이트와 일치한다.
- MainGame 씬 변경은 새 타일 매핑 3개, 6줄뿐임을 작업 직전 사본과 대조했다. 기존 사용자 씬 변경을 보존했다.
- 런타임 C#와 에디터 C#를 순차 컴파일: 모두 오류 0개. 증분 최종 출력은 각각 경고 0개이며, 앞선 에디터 컴파일의 기존 deprecated API 경고는 별도로 남아 있다.
- 저장 데이터/아이템 ID/레시피/광물 경도/설치 크기 변경 없음. B 영역은 아트 연결과 부족 목록만 처리했다.
- 런타임 표시·애니메이션·실제 플레이는 미검증. 전용 원본이 없는 항목은 미제공이며 후속 아트팀 전달 대상이다.

추후 18종의 전용 원본이 도착하면 연결 도구의 MissingItemArtIds에서 해당 ID를 제거하고 전용 경로를 등록해야 한다.

전체 연결 근거: [아이템 170종](아이템_170종_아트_연결_전수목록.csv), [Sprite 562개](카탈로그_Sprite_562개_전수목록.csv).
