# 10-4작업.zip 전체 수신 대조

> **10-4 납품 적용 후 최신 상태:** 아래는 적용 전 조사 이력이다. 현재 아이콘 154/170종 연결, 16종 미제공이며 설치물 50종 모두 연결했다. 미장이 인형 전체를 아이콘으로 공유한다. [최신 적용 결과](10-4_아트_적용_결과.md)를 기준으로 한다.

> **실제 크기 정정:** 최초 미리보기는 캔버스만 표시했다. 원시 셀과 Unity 임포트 확인 결과 포대·화차 실제 기본 그림은 27×32px이고 버섯은 64px 너비에 4종 개별 그림을 포함한다. 32×16은 포대 파일의 캔버스 값이며 실제 그림이 2×1이라고 해석하면 안 된다. [전체 셀 확인](10-4_캔버스밖_전체셀_확인.png) 참조.

ZIP: `D:/다운로드/박태영/대경잼/10-4작업.zip`
구성: `새 폴더/` 아래 Aseprite 16개. 파일 SHA256, 캔버스 크기, 프레임·태그와 실제 픽셀을 모두 확인하고 현재 프로젝트 Aseprite 전체와 대조했다. 현재 카탈로그의 실제 원본 경로도 확인했다. 동봉 문서는 없다.

## 결론

- 누락 아이콘 중 단일 전용 그림을 확실히 받은 항목은 5종: 신기전 손대, 한파 신기전, 지귀의 잉걸 재료, 영노의 탈 재료, 석이.
- 잉걸/탈은 같은 이름의 아티팩트 2종에도 공유 가능하므로 기존 26종 중 7종을 바로 해소할 수 있다. 아직 연결하지 않았으므로 게임 상태의 누락 26종은 그대로다.
- 누락 설치물 3종(도관 포대·한파 포대·미장이 인형)의 월드 그림은 모두 왔다. 포대 전용 작은 아이콘은 없고 월드 프레임 공유가 가능하다. 미장이 인형의 16×16 부분 그림 용도는 추가 확인 대상이다.
- 위 3종의 아이콘까지 같은 대상 그림 공유로 해결한다면 아이콘 요청은 26→16종으로 줄일 수 있다. 확정 아이콘·공유 가능한 그림·용도 확인 항목을 섞어 완료로 계산하지 않았다.
- 느타리·표고는 새 월드 전용 그림, 석이는 월드/아이콘 각각 별도 그림이 제공됐다. 기존 아이콘을 버섯 월드에 공유했던 상태를 해소할 수 있다.
- 성에 광석은 이미 적용된 원본과 동일하다. 지귀의 재와 신기전 화차에는 현재 연결과 다른 그림이 왔다.
- 보스 7종, 눈물 주머니, 저체온 상태 아이콘, 아래 아티팩트 16종은 이번 ZIP에 없다.

## 중요한 연결 차이

1. `jigwi_ember_mat.aseprite`는 현재 `Assets/Art/Items/DeliveredFinal/jigwi_ash.aseprite`와 바이트까지 같다. 새 `jigwi_ash.aseprite`는 별도 재 그림이다. 새 납품 기준으로 지귀의 재에는 새 ash를, 잉걸 재료·아티팩트에는 ember_mat를 연결해야 한다. 기존 서로 다른 아이템을 혼동한 상태를 방지하기 위해 동시 교체가 필요하다.
2. `cold_wave_battery`, `ice_root_battery`, `신기전`은 총 4프레임이며 `attack` 태그는 1~3(0부터 시작)을 가리킨다. 태그 밖 0번은 대기/기본 포즈에 대응하는 그림이다.
3. 현재 `MainGameEnvironmentState`는 건물 프레임을 `RuntimeBuildingSpriteAnimator.Configure`로 반복하고, 연결 도구는 가장 긴 애니메이션을 선택한다. 따라서 attack만 그대로 등록하면 발사하지 않아도 공격을 반복할 수 있다. 기본 포즈와 발사 시 1회 재생을 분리해야 한다.
4. `plaster_doll1`은 머리 그림, `plaster_doll2`는 하부/받침 그림이다. 번호를 열림/닫힘·손상 상태라고 추정하지 않는다.
5. 픽셀 크기는 원본 캔버스 기준이다. 포대/화차는 캔버스 32×16이나 실제 셀 27×32px다. 미장이 인형 전신은 1×2 캔버스지만 설치 점유·피벗·실제 렌더 크기는 별도 검증 대상이다.

## 검증 범위

- 16개 파일 전부 정상 파싱했고 첫 프레임 및 포대/화차의 4프레임을 미리보기로 직접 확인했다.

- Unity MCP 조회는 HTTP 응답을 받지 못했다. 서버 응답 실패와 Unity 세션 0개는 구분하며, 이번 결과로 세션 상태를 단정하지 않는다.
- 게임 코드·기존 아트·카탈로그·씬은 변경하지 않았다. 수신 대조 보고서·CSV·미리보기만 생성했다.
