# 최신 확정 아트 교체 결과 — 2026-10-04

사용자 확인에 따라 `본선.zip` 전체를 최신 확정 납품본으로 삼았다. 아래 보류는 리소스 확정 여부가 아닌 기존 대상·용도·상태와의 대응 문제다.

후속 적용: 대장간(`smithy`), 화살 보급대(`arrow_supply`), 징 울림대(`gong_tower`), 허수아비(`scarecrow`), 한파석(`cold_wave_ore`), 성에 광석(`seonge_ore`) 월드 아트를 추가 연결했다. 이정표 월드 아트까지 현재 납품 파일 반영은 154/172개, 미반영은 18개다. [임시 대체 전수조사](임시_대체_아트_전수조사.md)에서 잘못된 연결 해제와 추가 배선을 확인할 수 있다. 상세 검증은 [대장간](대장간_월드_아트_적용_결과.md), [보급대·징 울림대·허수아비](보급대_징울림대_허수아비_월드아트_적용.md), [한파석·성에 광석](한파석_성에광석_월드타일_적용.md)를 참조한다.

## 교체 결과

- 기존 연결이 명확한 원본 94개 교체: 지형·배경·제단 22개, 장식 8개, 설치물 26개, 아이콘 32개, 캐릭터 6개.
- 직전 작업에서 연결한 요청 아이콘 53개 원본과 배선을 유지했다. 합계 147개 납품 파일이 프로젝트에 반영됐다.
- 기존 Aseprite 92개는 경로와 GUID를 유지하며 원본 바이트만 교체했다. 임포트된 Sprite의 참조가 달라진 항목은 Unity 에디터에서 재연결했다.
- 기존 PNG를 사용하던 강철 몸통·제단 전체 타일은 납품 Aseprite를 추가하고 해당 참조만 교체했다. 이전 PNG는 다른 작업물 보존을 위해 삭제하지 않았다.
- 아이템 ID, 타일 에셋 GUID, 콜라이더·채굴 경도·레시피·저장 데이터와 UI 배치는 변경하지 않았다.
- B 영역은 요청받은 캐릭터 아트 카탈로그와 프레임 참조만 수정했다. 전투/스폰/보스 로직은 수정하지 않았다.
- `BuildingArtPreview.unity`의 구버전 애니메이션 프레임 5개를 제거해 최신 단일 프레임에 맞췄다. 현재 Title 씬은 저장하지 않았다.

## 검증

- 94/94 원본 SHA256 일치 및 Unity에서 Sprite 로드 확인.
- 직전 적용 아이콘 53/53 SHA256 보존 확인.
- 기존 경로 교체 92개: 원본 GUID 보존 확인.
- Unity MCP에서 아트/타일 에셋 26개의 Sprite 참조 370개 조회. 관련 GUID의 모든 .asset/.unity/.prefab 참조를 실제 Sprite fileID와 대조해 누락 0개 확인.
- CPU 빌드 순차 수행: 런타임 오류 0, 에디터 오류 0/경고 38. 최종 기본 Sprite 선택 코드 수정 후 에디터 재컴파일도 오류 0.
- Unity 에디터 콘솔 오류 조회 0건. 플레이 모드 진입·게임 실행·GPU 검증 없음. **인게임 표시·애니메이션 런타임 미검증**.

## 후속 수정: 나무 부분 원본의 독립 생성 제거

사용자 화면 대조로 tree_down/tree_up 조각이 독립 나무 종류에 사용되는 오류를 확인했다. tree_0/tree_1/tree_2는 모두 완성형 t_tree 원본(프로젝트 tree.aseprite)을 사용한다. 두 조각 원본은 보관되지만 독립 나무 연결에서는 제외했다. 따라서 앞의 94개 원본 교체 내역은 파일 반영 기록이며, 두 조각의 이전 독립 나무 연결은 현재 유효하지 않다. 상세 검증은 월드_아트_잘림_정적조사.md에 기록했다.
