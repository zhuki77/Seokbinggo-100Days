# 제작대 E 진입과 아이콘 대기열

- 가까이 가는 것만으로 제작대의 레시피가 표시되지 않는다. 기본 창은 손 제작 레시피와 손 제작 대기열을 표시한다.
- 마우스 커서를 올려 하이라이팅된 제작대에 E로 직접 상호작용한다. 진입 판정과 하이라이팅은 같은 조준 원점·사거리·가림 판정을 사용한다. 제작대의 종류와 objectId를 유지하여 해당 제작대의 레시피와 작업 대기열을 표시한다. 같은 종류의 다른 제작대와 작업을 섞지 않는다.
- 진입 중에도 WASD로 플레이어를 이동한다. 제작 목록의 키보드 탐색과 E 제작 실행은 제거하고 마우스로 선택·제작한다. 처음 진입할 때만 거리를 확인하며, 진입 후 멀리 이동해도 해당 제작대가 존재하는 동안 제작 연결을 유지한다.
- 다른 제작대 또는 상호작용 물체를 하이라이팅하고 E를 누르면 현재 제작대에서 나온 뒤 해당 물체와 상호작용한다.
- ESC로 제작대 UI를 닫으면 손 제작으로 돌아간다. 제작대에서 예약한 작업 자체는 취소되지 않는다.
- 제작창 오른쪽 옆, 아이템 목록의 세 번째 행과 같은 높이에 진행 1개 + 대기 4개의 결과물 아이콘을 표시한다. 작업이 존재하는 슬롯만 프레임을 보인다. 0개면 프레임 없음, 2개면 2칸이다.
- 첫 작업은 실제 remaining/duration 값으로 파란 반투명 부채꼴이 12시부터 시계 방향으로 채워진다. 대기 작업에는 타이머를 표시하지 않는다.
- 작업 아이콘 우클릭으로 해당 작업을 취소하고 기존 재료 환급 로직을 사용한다. 인벤토리 공간 부족으로 반환이 대기되거나 제련 완성품이 있으면 회수 버튼을 표시한다.
- 외부 HUD의 제작 진행바를 숨긴다. 대기열 데이터와 저장 형식은 변경하지 않는다.

## 플레이 확인

1. 작업대와 화로 옆에 서 있어도 손 제작 레시피만 표시되는지 확인한다. C로 제작 탭을 열어도 E 진입 전에는 손 제작이어야 한다.
2. 작업대에 E로 진입하고 작업을 5개 예약한다. 첫 칸부터 결과물 아이콘이 순서대로 표시되어야 하며 6번째 예약은 불가능해야 한다.
3. 0/25/50/75%에서 타이머 경계가 각각 12/3/6/9시 방향인지 확인한다. 완료 시 다음 작업이 첫 칸으로 이동해야 한다.
4. 작업 수를 2개와 0개로 줄인다. 각각 프레임 2개와 0개만 표시되는지 확인한다.
5. 진행 작업과 대기 작업을 우클릭해 각각 취소한다. 해당 작업의 재료가 반환되어야 한다. 공간이 부족하면 회수 버튼으로 반환 대기분을 받는다.
6. ESC로 나온다. 손 제작 레시피와 손 제작 대기열로 돌아가고, 제작대 작업은 계속 진행되어야 한다. 해당 제작대에 E로 다시 진입해 진행률을 확인한다.
7. 같은 종류의 제작대 2개에 서로 다른 작업을 예약한다. 각각 E 진입 시 그 제작대의 작업만 보여야 한다.
8. 화로/용광로의 제작·제련 전환에서도 같은 설비의 대기열을 공유하고 제련 완성품을 회수할 수 있어야 한다.
9. 저장·이어하기 후 제작대에 E로 진입하면 해당 설비의 저장된 작업이 표시되어야 한다. 화면 바깥의 이전 진행바는 나타나지 않아야 한다.
10. 일시정지 시 대기열도 어두운 배경 아래에 표시되고 조작할 수 없어야 한다.
11. 제작대 진입 중 WASD로 이동하고 멀리 떨어져 제작을 예약한다. 진입 연결이 유지되고 제작 완료 시 인벤토리가 즉시 갱신되어야 한다.
12. 제작대 진입 중 다른 제작대, 장독창고, 문 또는 상자를 하이라이팅하고 E를 누른다. 이전 제작대 진입이 종료되고 해당 대상과 상호작용해야 한다. 가려졌거나 하이라이팅되지 않은 대상에는 진입하지 않아야 한다.
13. Ctrl+F12로 현재 진행 작업만 즉시 완료한다. 삼두구미가 소환되지 않아야 한다.

코드 흐름과 CPU C# 컴파일만 확인한다. Unity/게임 실행 및 GPU 검증은 수행하지 않는다.
