# 기획 확정: 이무기·강철이 역할 정정

2026-10-06 사용자가 기획자·아트팀에 직접 확인하고 전달한 변경. 최신 수정 기획서는 아직 미수령이며 이 사용자 확정을 기존 v86 문서·CSV보다 우선한다.

| 역할 | 확정 명칭 | 기존 문서 및 구현상의 명칭·ID |
|---|---|---|
| 30일차 최종 보스 | 강철이 | 이무기, imugi_boss / BossKind.Imugi |
| 18일차부터 심층에 등장하는 정예 몬스터 | 이무기 | 강철이, gangcheol / YokaiKind.Gangcheori |

- 기존 기획서의 두 몬스터 역할·명칭이 잘못 적혀 있었다. 아트만 잘못 연결됐다고 단정하거나 기존 문서로 사용자 확정을 되돌리지 않는다.
- 원본 아트의 imugi/2mugi와 gangcheol/강철 명칭은 확인된 캐릭터 정체에 맞추며, 실제 역할을 구현할 때 이름·아트·안내·데이터·보상·세이브 ID 영향 범위를 함께 검토한다.
- 이 확정은 두 몬스터의 역할·정체 정정이다. 체력·패턴·보상 수치나 스폰 일정 등 나머지 설계를 임의로 추가 변경하지 않는다. 세부 대응이 불명확하면 별도로 확인한다.
- 사용자 후속 적용 지시에 따라 코드·CSV·실제 데이터 SO의 역할 표시 및 아트 연결 교체 완료. 세이브 ID는 변경하지 않았다.

## 실제 적용 결과

| 적용 대상 | 30일차 강철이 | 18일차 심층 이무기 |
|---|---|---|
| 저장·조건 판정용 ID | imugi_boss / imugi 유지 | gangcheol 유지 |
| 원본 머리·몸통·꼬리 | gangcheol 계열 | imugi 계열 |
| 조립 비주얼 | 기존 RuntimeImugiBodyVisual 유지 | 기존 RuntimeGangcheoriBodyVisual 유지 |
| 체력·기존 행동 | 16000 / 기존 최종 보스 행동 유지 | 2800 / 기존 심층 정예 행동 유지 |
| 보상·해금 | 여의주·눈물 및 기존 결과/진행 판정 유지 | 역린·가뭄 심장 및 기존 제작 해금 유지 |
| 개발 호출 | Ctrl+F7 | Shift+F9 |

- 목표 g15, 안내 goal_imugi, 결과 화면, 개발 키 설명, 보스·요괴·도감·지형 스폰·지역 등의 CSV/SO 이름을 정정했다. 아이템의 고유 이름과 ID는 유지하고 획득 출처 설명을 정정했다.
- 도감 초상은 레거시 역할 ID에서 실제 캐릭터 아트 ID로 변환한다. 기존 이무기/강철이 도감 출처·뒷면 내용도 정체에 맞게 교환한다. 미확인 전승 문구는 새로 지어내지 않았다.
- 30일 보스 체력 프레임은 강철이 프레임(공통 시트 4번째 행)으로 변경했다. 31일 이후 확장 보스 불볕 강철이·강철이 완전체의 정체·아트는 유지한다.
- 사용자 후속 요청으로 조립 컴포넌트 교체와 0.68→0.45칸 간격 조정을 롤백했다. 아트 참조만 교환하며 몸통 수량·간격·위치·움직임 및 부위별 피격 판정은 각 역할의 기존 조립 코드를 유지한다.
- 실제 SO는 Unity MCP SerializedObject로 수정·저장 후 보스/정예/목표/안내 표시를 재조회했다. CSV도 같은 확정 내용으로 변경했다. 최신 기획서를 새로 받을 때 본 문서와의 정체·역할 정합을 먼저 확인해야 한다.
- 기존 회귀 검증의 체력 프레임 행 및 정예 키 표시 기대값도 갱신했다. CPU C# 컴파일 런타임 오류 0/경고 3, Editor 오류 0/경고 38. Unity/게임 신규 실행·플레이 테스트·GPU 검증은 수행하지 않았다.

플레이 확인: Ctrl+F7 보스 이름·머리·몸통·체력 프레임이 강철이인지, Shift+F9 심층 정예가 이무기 모습인지, 도감과 g15 안내·격파 결과 이름이 일치하는지, 기존 세이브의 격파·해금 기록이 보존되는지 확인한다.
