# 체력 HUD 하단 알람 정렬

2026-10-06 사용자 확정: 저체온·화상·침공·백중날·보스 알람을 체력 오른쪽 대신 아래에 가로로 표시한다. 활성화 순으로 왼쪽부터 추가하고 해제 시 빈자리를 당겨 채운다.

- 기존 PlayerStatusArt 아래에 12×12 아이콘, 가로 간격 14로 배치한다. 후속 사용자 기획 확정으로 발톱 티어 T1 표기를 숨기고 알람 줄 시작을 PlayerStatusArt의 왼쪽 X=0으로 옮겼다(이전 X=14.5). 아이콘 확대/축소 효과는 추가하지 않는다. 실제 발톱 티어 및 채굴 판정은 유지한다.
- 활성 아이콘 목록은 프레임 간 유지한다. 새 활성은 끝에 추가, 해제는 해당 요소만 제거, 나머지 순서는 유지한다. 재활성화는 끝에 추가한다. 같은 프레임에 처음 감지된 상태는 저체온·화상·침공·백중날·보스 순으로 추가한다.
- 저체온과 실제 화상 상태를 연결하고, 침공·백중날·강제 등장 보스의 낮 예고 및 해당 밤/전투 상태를 표시한다. 예고에서 실제 상태로 전환할 때 같은 알람 슬롯을 유지한다. 보스 전투 시작은 기존 전투 아이콘으로 전환한다.
- 원본 아이콘을 재사용한다. 저체온은 HypothermiaStatusIcon, 보스 전투는 NightSpawnBlockedIcon, 보스 예고는 BossWarningSmall, 화상·침공·백중날은 기존 안내 배지가 사용하던 DangerIcon이다.
- MainGameGoalUiController의 별도 GuideStatusBadges를 제거하여 중복 표시를 막는다. 한 줄 안내와 우선순위는 유지한다.
- 제작·가방·일시정지·타이틀 복귀 확인창에서 이 알람 줄은 숨긴다. 숨겨도 활성 순서를 지우지 않으며 닫으면 같은 순서로 복귀한다. 일시정지 하단 저장 불가 안내는 별도 UI로 유지한다.

검증: Unity MCP로 현재 HealthFill → PlayerStatusArt → GameplayHUD 앵커와 T1 표기 위치를 조회했다. 상태 변화·삭제·재활성화·메뉴 숨김 코드 흐름을 정적으로 검토하고 CPU C# 컴파일을 수행한다. 게임 실행·GPU 검증은 하지 않는다.

사용자 확인 예: 침공 알람 → 저체온 → 화상 순으로 활성화하면 왼쪽부터 해당 순서로 표시. 저체온을 해제하면 침공·화상이 붙어 표시되고, 다시 저체온이 되면 맨 오른쪽에 추가. 메뉴를 열면 숨고 닫으면 복귀한다.

후속 위치 조정: 사용자 사진의 체온계 중심축에 첫 아이콘 중심이 맞도록 알람 줄 시작을 X=0에서 X=3으로 이동했다. 12px 아이콘의 첫 중심은 X=9이다. 높이·크기·아이콘 간격과 활성 순서는 유지한다.
