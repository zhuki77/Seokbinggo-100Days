# 밀폐실 햇빛 틱 피해 면제

2026-10-06 사용자 전달 기획자 컨펌: 지상 낮이라도 플레이어가 밀폐된 공간 안에 있으면 햇빛 틱 피해를 받지 않는다.

- DayHeatDamageService에 기존 SealSystem을 전달하고, 플레이어 현재 위치의 IsInsideSealedArea가 참이면 낮 화상 피해를 적용하지 않는다. 코어 설치 여부나 온도 조건을 추가하지 않는다.
- IsBurnActive 안내 판정과 실제 Tick 피해 판정이 같은 노출 조건을 사용한다. 밀폐실 안에서는 햇빛 화상 안내도 비활성화된다.
- 밀폐실에 들어가면 소수 피해 누적값을 초기화한다. 밖으로 나오거나 문·벽 변경으로 밀폐가 깨지면 기존 지상 낮 피해 조건과 배율이 다시 적용된다.
- 체온 상승 및 저체온 피해 규칙은 변경하지 않는다. 이번 컨펌은 햇빛 틱 피해 면제에 적용한다.
- 검증: 코드 흐름 정적 검토 및 CPU C# 컴파일. Unity/게임 실행 및 런타임 검증 없음.

플레이 확인: 지상 낮에 실외에서 피해 → 밀폐실에 들어가 문을 닫으면 피해 중단 → 문을 열거나 벽을 제거하면 피해 재개. 밀폐실에서 나와도 피해가 재개되어야 한다. 저체온 조건의 피해는 별도 규칙대로 유지되어야 한다.
