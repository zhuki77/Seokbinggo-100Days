# 보금자리 피격 후 휴식 제한

2026-10-06 사용자 확정: 피해를 받고 있을 때 휴식으로 시간을 넘길 수 없으며, 자연회복이 활성화되는 시점부터 휴식 가능.

- PlayerHealthRecoveryService.IsNaturalRecoveryReady는 생존 상태·마지막 피해 후 자연회복 대기시간·유효 회복 배율을 사용한다. HP가 가득 찼는지는 이 자격 판정에서 제외하여 만피도 휴식 가능하다.
- 실제 회복과 휴식 자격이 같은 회복 배율 계산을 사용한다. 피해 이벤트마다 대기시간이 초기화되며 햇빛·저체온 등 환경 피해도 같은 이벤트 경로를 사용한다.
- BedService.CanSleep에 자격 검사를 연결했다. 최초 상호작용과 TrySleep의 최종 시간 넘김 직전에 모두 재검사한다. 불가능하면 자연회복 시작까지 기다리라는 문구를 표시한다. 기존 온도·침공 제한도 유지한다.
- 현재 globals hp_regen_delay=10 게임초, MainGame의 회복 설정 덮어쓰기는 꺼져 있다. 별도의 휴식 타이머나 수치를 추가하지 않았다.
- 기존 로드 후 ResetAfterRestore 역시 회복 대기시간을 초기화하므로 불러오기 직후 휴식으로 제한을 우회할 수 없다. 새 게임도 기존 회복 대기시간이 경과해야 한다.
- 코드 흐름 정적 검토 및 CPU C# 컴파일. 실제 플레이·Unity 테스트 실행 없음.

플레이 확인: 피해 직후 보금자리 사용 차단 → 추가 피해가 없으면 10 게임초 후 휴식 가능 → 도중에 피해가 들어오면 다시 10초 대기. 회복 아이템으로 만피가 되어도 대기시간은 유지되어야 한다. 저장·불러오기 직후에도 기존 회복 대기를 건너뛰지 않아야 한다.
