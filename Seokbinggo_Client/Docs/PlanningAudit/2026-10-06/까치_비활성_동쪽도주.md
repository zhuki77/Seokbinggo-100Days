# 까치 비활성 시 동쪽 도주

2026-10-06 사용자 요청: 활성 조건이 깨지면 즉시 사라지지 않고 동쪽(오른쪽)으로 날아가 화면 밖에서 사라진다.

- 둥지 철거·밀폐 해제 등 기능 조건 상실 시 당일 활성은 즉시 해제하고 수집을 취소한다. 표시 중인 까치만 도주 상태로 전환한다.
- 도주 중에는 수집·목표 안내·둥지 복귀를 하지 않고, 오른쪽 5칸/게임초·위쪽 2.5칸/게임초로 이동한다. 후속 사용자 확정에 따라 오른쪽 2칸마다 위쪽 1칸씩 상승한다.
- 게임 카메라의 오른쪽 또는 위쪽 경계 밖으로 까치 스프라이트 전체가 나가면 숨긴다. 카메라가 없는 비게임 환경에서는 출발 위치보다 32칸 오른쪽에서 종료한다.
- 같은 날 밀폐를 복구해도 즉시 돌아오지 않으며 기존 다음 아침 활성 규칙을 유지한다. 저장은 기존 당일 비활성 값을 보존하고 도주 연출 자체는 저장하지 않는다. 복원 시 이전 도주 표시를 초기화한다.
- CPU C# 컴파일과 코드 흐름 정적 검토로 검증. 실제 게임 실행·플레이 검증 없음.

플레이 확인: 낮 동행 중 또는 밤 둥지 휴식 중 문을 열어 밀폐 해제 → 오른쪽으로 상승 비행(가로:세로 2:1) → 스프라이트 전체가 화면 밖에서 사라짐. 도주 중에는 아이템을 줍지 않아야 한다. 같은 날 밀폐 복구 및 저장·불러오기 후 비활성 유지, 다음 아침에는 조건 충족 시 재활성화 확인.
