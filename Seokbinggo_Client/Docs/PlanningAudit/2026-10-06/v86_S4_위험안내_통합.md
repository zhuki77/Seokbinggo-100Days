# v86 S4 위험 안내 통합

2026-10-06. 개발 A 상태 연결 + 개발 B UI·표시 이력 저장 구현 완료. CPU 정책 검사와 C# 컴파일 확인. 사용자 인게임 검증 대기.

정본: v86 `05_안내시스템_명세·데이터.md` S4 및 A4/B4. 안내 문장·tier·repeat는 기존 GuideMessageDefinition/CSV를 사용한다. 최신 사용자 확정인 밀폐 경고 노란색, 보스·저체온 HUD 아이콘 크기·위치는 유지한다.

후속 사용자 확정(2026-10-06): 일시정지의 보스 배지는 하단 저장 불가 문구 왼쪽으로 통합·중앙 정렬. 일시정지의 추가 저체온 배지는 숨김. 아래 초기 S4 메뉴 정책보다 이 후속 요청을 우선한다.

최신 사용자 기획 정정(2026-10-06): UI 개편을 앞두고 메뉴에서 tier 1·2 작은 안내 아이콘을 유지하는 정책을 폐기했다. 제작·가방·일시정지 및 타이틀 복귀 확인창 등 메뉴가 열려 있으면 안내 배지를 모두 숨기고, 닫으면 유효한 한 줄 안내로 복귀한다. 기존 체력 HUD 상태 아이콘과 별도로 요청한 일시정지 하단 저장 불가 아이콘은 이 공통 안내 배지 정책과 구분한다.

## 변경

- GuidePriorityQueue는 숫자가 작은 tier를 우선하며, 같은 tier는 가장 최근 활성화/이벤트 발생 순으로 선택한다. 매 프레임 같은 상태를 조회해도 순서를 갱신하지 않는다.
- 위험(저체온·실제 낮 화상) → 전투·행사(보스 전투·침공 밤·낮 예고) → 건축·보관 반응 → 현재 선택 목표를 주 안내 하나로 표시한다.
- while_active는 상태가 끝날 때 제거. once_per_event/on_each는 이벤트마다 표시. once_per_day/once_per_dawn은 해당 일차의 표시 완료 이력을 기록한다. 짧은 안내는 실제 표시된 시간 3초 후 종료하며 가려져 있는 동안은 시간을 소모하지 않는다.
- 메뉴·일시정지에서는 주 안내·목표·건축 표식과 모든 안내 배지를 숨긴다. 저체온/보스 HUD의 기존 아이콘은 유지한다. 메뉴를 닫으면 유효한 안내로 복귀하고 가려진 동안 표시 시간을 소모하지 않는다.
- 낮 예고는 3초 강조 후 작은 배지로 남고 밤 시작 시 제거한다. 기존 HUD의 지속 침공 문장 배너를 공통 엔진으로 대체했다.
- 전투·위험 중에는 건축 윤곽/문 강조·목표 화살표·목표 선택 목록·새벽 결과 패널을 숨긴다. 위험 종료 후 현재 살아 있는 안내와 미확인 새벽 결과로 돌아간다. 결과 확인 전 g09 완료 처리하지 않는다.
- 건축 이벤트·보관 조건 충족·새벽 손실/유지·차가운 침대 사용 실패를 연결했다. 용기별 상세 새벽 결과/온도 정보는 기존 패널에 유지한다. S7 전용 손상/열기 제거 안내는 다음 S7 범위다.
- DayHeatDamageService.IsBurnActive는 실제 화상 피해의 지상 노출·밤 여부·단계·피해 배율을 사용한다. 온도 변화나 피해 수치를 변경하지 않는다.
- 저장 스키마 29→30. GoalProgressRecord에 guideDay/consumedGuideIds 추가. 같은 날의 소비된 예고를 이어하기에서 다시 강조하지 않는다. 과거 저장은 빈 표시 이력으로 이관하며 진행 목표·보관 결과는 유지한다. 복원 시 일회성 성공 연출을 재생하지 않는다.

## 소유 영역 및 검증

- A: GuidePriorityQueue, MainGameGoalTracker, DayHeatDamageService, BedService, MainGameTurretRuntime의 침대 실패 이벤트 전달.
- B: MainGameGoalUiController, MainGameHudController, MainGameBuildingGuideUiController, SaveGame. 기존 저장·HUD 변경분과 합칠 때 겹침 확인 필요.
- 실제 Queue 소스를 연결한 독립 CPU C# 정책 검사 19개 통과. Unity ScriptableObject 대신 데이터 전용 스텁을 사용하므로 씬·Unity UI·세이브 JSON 입출력의 런타임 검증은 아니다.
- CPU C# 컴파일: 런타임 오류 0/경고 3, Editor 오류 0/경고 38. 변경 파일 공백 검사 통과.
- Unity MCP editor/state: Title 씬, 비플레이·컴파일 중 아님 확인. 콘솔 오류 조회 도구는 이번 세션에 노출되지 않아 콘솔 검증 완료로 주장하지 않는다.
- Unity/게임을 새로 실행하지 않았으며 플레이 모드·GPU 검증 없음. 기존 까치 검증은 사용자 보고 완료로 별도 보존한다.
