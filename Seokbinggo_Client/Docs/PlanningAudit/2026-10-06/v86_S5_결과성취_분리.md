# v86 S5 결과 화면 성취 분리

2026-10-06. 정본: v86 `05_안내시스템_명세·데이터.md` S5 및 A5/B5, 현재 globals/modules/goals CSV. 사용자 기획 정정에 따라 데모 보스 표기는 강철이이며 저장 ID `imugi_boss`는 유지한다.

## 적용

- 결과 화면은 보스 격파(강철이), 석빙고 완공/미완공(핵심 모듈 n/5), 보관 성공(새벽 보존 확인)을 각각 표시한다.
- modules.csv의 아이템이 있는 설치 모듈만 집계한다. `seokbinggo_s1~s6` 단계 행, 중복, 알 수 없는 ID는 제외한다. 분모는 win_modules를 사용하고 실제 핵심 모듈 종류 수가 일치하는지 검증한다.
- 기존 모듈 설치 판정을 재사용하여 차열벽/지붕의 현재 전경 타일과 문/장독/얼음 저장고의 현재 설치 상태를 읽는다. 존재했다가 철거된 모듈은 현재 설치 수에 포함하지 않는다.
- 보관 성공은 g09 달성 이력이다. 얼음을 넣기만 했거나 새벽 결과가 발생했지만 아직 확인하지 않은 상태로 성공을 만들지 않는다.
- demo_complete_rule=boss_and_core_modules에 따라 관문 격파와 현재 핵심 모듈 5종이 동시에 충족되면 데모 완성을 달성 기록으로 유지한다. 관문 격파 후 계속 플레이하며 나머지 모듈을 설치해도 갱신한다. 이후 건축물이 사라지면 현재 n/5는 줄지만 이미 달성한 데모 완성 기록은 보존한다.
- SaveGame에 storageSuccess/demoComplete 선택 필드를 추가했다. 기존 schema 31을 유지하며 필드가 없는 저장은 기존 g09/보스/모듈 기록에서 성취를 다시 계산한다. MainGameGoalTracker가 플레이 중 완성 기록을 유지하고 통합 스냅샷 캡처/복원에 연결한다.
- 결과는 관문 격파 시 모듈 수와 무관하게 열린다. 보스 접근 잠금, 새 보상 지급, 전투·보관 수치 변경은 없다. 보상 안내는 관문 데이터의 확정 드랍 이름을 사용하여 바닥에서 회수하라고 표시한다.
- 기존 밀폐율을 0/-5/-10℃로 추정하던 결과 상단 표시는 실제 절대 방온과 다르므로 성취 상태 문구로 교체했다. 계속 플레이/타이틀 버튼과 통계는 유지한다.

## 소유 영역

A: SeokbinggoRules의 성취 정책, MainGameGoalTracker의 실시간 완성 상태.
B: GameShellController/결과 UI 및 MainGameSaveCoordinator/SaveGame 성취 저장. 사용자의 S5 전체 진행 요청 범위로 함께 연결했고, 기존 변경분은 보존한다.

## 검증

- 실제 SeokbinggoRules.cs와 현재 CSV를 연결한 독립 CPU 정책 검사 30/30 통과. 핵심 5/전체 11, 중복/단계 제외, 미격파/격파 × 0~5종, 나중 완공, g09 성공, JSON 복원, 철거 이후 성취 유지, 구 저장 기록 추론, 분모 불일치 거부를 검사했다. Data/Save의 Unity 비의존 대체 타입을 사용하므로 Unity 런타임 검증은 아니다.
- Editor 회귀 코드에도 결과 성취 분리, 미완공 상태의 결과 진입, 미확인 새벽 제외, 확장 보스 혼동 방지를 추가했다. 해당 테스트는 실행하지 않았다.
- 런타임 및 에디터 CPU C# 컴파일 오류 0개. Unity/게임 실행, 화면 확인, GPU 검증은 하지 않았다.
- Unity 콘솔의 기존 guideDay 0→1 왕복 불일치는 별도 기존 결함으로 남아 있다.

재실행: `dotnet run --project Docs/PlanningAudit/2026-10-06/S5CpuChecks/S5CpuChecks.csproj --no-restore`.

## 실제 플레이 확인

1. 핵심 모듈 5종 중 일부만 갖춘 상태에서 강철이를 격파한다. 결과가 열리고 정확한 n/5, 석빙고 미완공이 표시되어야 한다. 단계 승급 행은 목록에 없어야 한다.
2. 얼음을 보존했지만 새벽 결과를 확인하기 전에는 보관 성공이 미확인이다. 결과를 확인하여 g09 달성 후에는 성공이 표시되고 저장/이어하기에서도 유지된다.
3. 미완공 결과에서 계속 플레이 후 나머지 모듈을 설치하고 저장한다. 이어하기에서도 완성 기록이 유지되어야 한다. 데모 보스를 재격파해 결과를 열면 완성 상태가 표시되어야 한다.
4. 완성 후 일부 모듈을 철거하면 현재 n/5는 줄어야 한다. 이미 달성한 데모 완성 기록은 유지된다.
5. 결과에서 보상 안내와 두 버튼이 겹치지 않고, 계속 플레이 후 실제 드랍을 회수할 수 있어야 한다. 결과 화면이 보상을 중복 지급하지 않아야 한다.
