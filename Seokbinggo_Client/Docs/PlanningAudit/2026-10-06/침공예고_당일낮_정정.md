# 침공 예고 일차 정정

2026-10-06 사용자 보고: 6일차 낮 예고로 안내받았으나 실제 5일차 낮에 표시됨.

- 원인: 기존 InvasionScheduleRules.ShouldShowAnnouncement가 `IsInvasionNight(day + 1)`을 호출했다. 구 v71의 전날 낮·내일 밤 규칙과 현재 v86 guide-messages.csv `invasion_tonight`의 오늘 밤 문구가 충돌했다. HUD 일차 표시 오류가 아니라 예고 조건이 하루 빨랐다. 이전 답변의 당일 낮 설명은 수정 전 코드와 일치하지 않았다.
- 수정: 침공 당일 낮 `IsInvasionNight(day)` 판정으로 통일하고 레거시 배너도 오늘 밤 문구로 정정했다. 침공 일정(6·16·26…96일차 밤), 침공 밤 휴식 잠금, 백중날/보스 일정은 유지한다. 공통 함수를 사용하는 한 줄 안내와 하단 HUD 아이콘에 함께 적용된다.
- CPU 검증: 실제 소스에서 Unity에 의존하지 않는 일정 메서드를 추출하여 C#으로 컴파일하고 1~100일차의 낮·밤·예고 비활성 상태 총 300개 조건을 확인했다. 낮 예고는 6·16·26·36·46·56·66·76·86·96일차에만 참이다. 관련 기존 Editor 회귀 검사도 갱신했다.
- Unity/게임 실행 및 GPU 검증 없이 코드 흐름·CPU 컴파일로 검증한다.
