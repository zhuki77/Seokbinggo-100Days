# 장독 얼음 손실 올림

2026-10-06 사용자 요청: 보관 온도 미달 시 장독의 일일 얼음 손실량을 올림한다.

- 장독 일일 손실량 = ceil(현재 스택 수량 × 적용 손실률), 최대 현재 수량.
- 기본 손실률은 기존 globals.storage_melt_per_day=0.25이며 기존 장비 배율도 유지한다. 보관 온도 충족 시 손실 없음. 적용 손실률 0이면 손실 없음.
- 기본 25% 기준: 1개 → 0개, 2개 → 1개, 4개 → 3개, 5개 → 3개, 99개 → 74개.
- 구 세이브의 소수 누적값은 새 장독 손실 계산에 합산하지 않으며, 처리 후 0으로 초기화한다. 세이브 필드를 제거하거나 스키마를 변경하지 않는다.
- 새벽 결과의 전후 수량·손실 개수는 실제 차감 결과를 그대로 사용한다. 자연 새벽과 침대 시간 이동 모두 기존 일일 처리 경로로 적용한다.
- 가방 및 바닥 드롭의 실외 용해는 기존 계산을 유지한다.

검증: 정적 산식·호출 경로 검토, CPU C# 컴파일. 게임/Unity 실행·런타임 검증은 수행하지 않는다. 기존 S3 보고서의 소수 누적 설명은 변경 이전 이력이다.
