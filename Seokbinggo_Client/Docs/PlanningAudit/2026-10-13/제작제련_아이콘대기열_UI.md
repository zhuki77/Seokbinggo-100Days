# 제작·제련 아이콘 대기열 UI

## 변경 내용

- 제작과 제련 화면 왼쪽 아래에 진행 1개 + 대기 4개의 흰 테두리 슬롯을 동일하게 표시한다.
- 각 슬롯에는 실제 해당 제작대 작업의 결과물 아이콘을 표시한다. 제작/제련 목록 전환은 같은 제작대 대기열을 공유하며, 다른 제작대는 기존처럼 별도 대기열을 사용한다.
- 진행 슬롯에 파란 반투명 부채꼴을 시계 방향으로 채운다. 진행률은 실제 작업의 `1 - remaining / duration`이다. 0%는 12시, 25%는 3시, 50%는 6시, 75%는 9시다. 제련이 일시 정지되면 실제 남은 시간이 멈추므로 표시도 함께 멈춘다.
- 각 작업 아래 취소 버튼은 기존 작업 참조와 취소/환급 로직에 연결한다. 오른쪽 회수 버튼으로 완성품과 반환 대기 재료를 받는다.
- 기존 월드 HUD의 제작 진행바를 숨긴다. 제작대 내부 아이콘에서만 작업 진행을 표시한다.
- 기존 설명란 안의 텍스트 대기열을 제거하고 설명 스크롤 영역을 확장한다.
- 제련 화면은 왼쪽 세로 결과물 아이콘 목록, 오른쪽 재료/연료/조건 설명, 하단 5칸 대기열로 구성한다. 이전/다음 버튼을 숨기고 클릭 또는 W/S·위/아래 방향키로 선택한다. Q로 제작/제련 전환한다.

## 실제 플레이 확인

1. 작업대에서 시간이 있는 제작을 5개 예약한다. 첫 칸과 대기 1~4의 아이콘 및 순서를 확인한다. 여섯 번째 예약은 기존 용량 제한에 걸려야 한다.
2. 첫 작업이 진행될 때 파란 영역이 12시부터 시계 방향으로 증가하는지 확인한다. 완료되면 다음 작업 아이콘이 첫 칸으로 옮겨지고 그 작업의 실제 진행률부터 표시되어야 한다.
3. 진행 작업과 대기 작업을 각각 취소한다. 해당 작업만 제거되고 예약 재료가 환급되어야 한다. 인벤토리가 가득 차면 반환 대기분을 회수 버튼으로 받을 수 있어야 한다.
4. 화로와 용광로에서 제련 UI를 연다. 이전/다음 버튼이 없고 세로 아이콘 클릭 및 W/S로 선택 항목과 설명이 함께 바뀌는지 확인한다. 긴 목록은 키 선택에 따라 선택 아이콘이 스크롤 안으로 들어와야 한다.
5. 같은 화로에서 Q로 제작/제련을 바꿔도 대기열이 유지되는지 확인한다. 다른 제작대로 이동하면 해당 제작대의 대기열을 표시해야 한다.
6. 제련 중 빙결에 의해 설비가 정지하면 타이머 진행도 멈추는지 확인한다.
7. 완성품 회수, 설치 가능한 제작품의 설치 버튼, 기존 TEST 즉시 완료와 ESC 닫기가 겹치지 않고 사용 가능한지 확인한다.
8. 설명이 길 때 오른쪽 설명 스크롤을 확인한다. 하단 취소/예약/회수 버튼과 안내문이 겹치지 않아야 한다.
9. UI를 닫으면 월드 HUD에 이전 제작 진행바가 나타나지 않아야 한다. 저장·이어하기 후 UI를 다시 열면 저장 당시 작업 및 진행률이 복구되어야 한다.

## 검증 범위

코드 흐름 및 CPU C# 컴파일로 확인한다. Unity/게임 실행, Play Mode, GPU 검증 및 수동 플레이 검수는 수행하지 않는다. 대기열 데이터 및 저장 형식은 변경하지 않는다.
