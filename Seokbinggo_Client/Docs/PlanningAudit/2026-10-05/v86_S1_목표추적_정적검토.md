## 저장 호환

- 스키마 27 → **28**. 최소 호환 스키마 **23 유지**. 목표 필드 없는 구 저장은 빈 목록으로 정규화하고 실제 복원 상태로 재평가한다.
- 구 배지 기록은 구 저장 호환용으로 남긴다. 새 목표가 연결되면 구 배지의 완료 효과를 억제해 소리 중복을 방지한다. 새 목표에는 3일 소멸 규칙이 없다.
- 구 저장의 배지 '작업대 제작'이나 침대 설치로 새 목표 완료·휴식 이력을 추측하지 않는다. 휴식과 새벽 확인은 기존 완료 기록이나 실제 새 이벤트가 필요하다.
- 새벽 유지 결과를 아직 표시하지 못한 상태도 저장한다. 이어하기 후 표시할 수 있으므로 새벽 자동 저장 직전에 확인하지 못했다고 결과가 사라지지 않는다.
- 같은 씬 내 복원에서도 HUD 표시 캐시를 초기화해 다른 저장의 새벽 문구가 남지 않도록 한다.
- 사용자 저장 파일을 읽거나 쓰거나 삭제하는 검증은 하지 않았다. 저장·이어하기 실제 실행은 미검증이다.

## 방향 안내 아트 보류

`ui_raid_arrow`라는 에셋은 실제 프로젝트 검색 결과 0개이며 본선 ZIP에서도 대응 원본을 찾지 못했다. `GameplayArtCatalog.GoalDirectionArrow`는 미연결이다.

- 자원·시설·코어·제단·얼음 호수 목표 좌표 해결과 화면 밖 화살표 표시 코드는 연결했다.
- 까치가 같은 좌표를 사용하도록 연결했다. 자원 검색은 목표 변경/월드 복원 때 후보를 모으고 이후 후보 목록에서 가까운 지점을 고른다. HUD 매 프레임 전체 월드를 스캔하지 않는다.
- **화면 가장자리 화살표는 전용 원본 미확인으로 표시되지 않는다.** 위험 아이콘·다른 아이템 그림·임의 생성 그림으로 대체하지 않는다.
- 아트 담당자 전달: `ui_raid_arrow` 원본과 기본 지시 방향 확인 필요. 원본 픽셀 크기는 확인 필요. 납품 후 `GameplayArtCatalog.goalDirectionArrow`에 대응 Sprite를 연결하고 방향 회전을 점검한다.

따라서 S1 전체 합격 기준 충족이나 인게임 완료라고 단정하지 않는다.

### 중간 콘솔 예외 관찰

- 한 조회에서 `NullReferenceException` 6개를 읽었고, 스택 포함 재조회에서는 0개였다. 콘솔 재조회 0개만으로 과거 예외가 해결됐다고 판단하지 않는다.
- 연결된 에디터의 실제 로그 경로는 `Application.consoleLogPath`로 확인한 프로젝트 `Logs/Editor.log`다. 기본 사용자 폴더의 Editor.log에는 해당 기록이 없었다.
- 실제 로그의 위치는 `MainGamePlayerController.Update()` 549행, `wireSnare.Tick(Time.deltaTime)` 호출이다. 새 목표 코드의 예외 스택은 해당 최근 로그에서 확인되지 않았다.
- `wireSnare` 생성은 플레이어 `Initialize()`에 있으나 생성 누락/참조 초기화가 발생한 정확한 계기는 확인되지 않았다. 스크립트 재컴파일 중 참조 소실 가능성은 추정이며 확정 원인이나 해결로 표현하지 않는다.
- 플레이어 컨트롤러는 이번 S1 단계에서 수정하지 않았다. 이 예외는 **미해결 후속 검토 항목**이다. 게임을 실행하거나 플레이 모드로 재현하지 않았다.

## 담당 경계와 후속 확인

- A 상태 영역: `GoalProgress`, `MainGameGoalTracker`, `MainGameRuntimeServices`, `BedService`, `StorageTemperatureService`.
- 이번 요청에 필요한 B 연결 영역: 목표 UI 신규 파일, HUD 배선, `SaveGame`, 저장 코디네이터, 구 배지 효과 억제, GameplayArtCatalog의 화살표 참조 필드. 이 파일은 B와 동시 수정 시 충돌 확인이 필요하다. 기존 다른 변경은 보존했고 씬·프리팹을 재생성하지 않았다.
- 수동 플레이 확인: 새 게임 g01→g09, 시설 철거 후 완료 유지, P1 선택 유지, 중간 저장·이어하기, 구 스키마 27 저장의 재평가, 표시 전 새벽 자동 저장 이후 이어하기, 복원 실패 롤백, 메뉴·사망·전환 시 HUD 가림, 차열벽·지붕 포함 5종 집계.
- 후속 단계는 S2 건축 도우미다. S3 손실 원인·용기별 새벽 결과, S4 위험 우선순위, S5 결과 성취는 이번 단계의 유지 확인 표시와 구분해 추가 구현한다.

최신 아트·버섯 99/A·장비 3열 보존은 유지한다. CSV 문구를 임의로 추가하지 않았고 커밋·푸시하지 않았다.
