# S1~S3 잔여 보완 결과

2026-10-05. 상태: 코드 보완 완료, 전용 아트 4종 미제공/원본 미확인으로 표시 완료는 보류. 게임·Unity 신규 실행 및 플레이 검증은 하지 않았다.

## 보완

- S2~S3 밀폐 성공: GameplayArtCatalog.SealSuccessFrames와 재생 경로를 추가했다. SealedNow 이벤트 때 코어 중심에서 원본 크기/PPU를 유지해 프레임당 0.12초로 1회 재생한다. 코어 변경·밀폐 해제·메뉴 진입·복원 때 종료하여 이전 연출이 남지 않는다. 원본이 없으면 그림을 생성하거나 다른 아트로 대체하지 않는다.
- 아트 적용: NyangbingoTileArtIntegrator.ApplyS1S3GuideArt(arrowPath, leakPath, repairPath, successPath). 기획 대응이 확인된 프로젝트 Aseprite 경로만 전달한다. 화살표/체크 1프레임, 누출 2프레임, 성공 3~4프레임을 확인한다. 전달하지 않은 항목의 기존 참조와 다른 카탈로그 항목은 유지한다. 잘못된 입력이면 카탈로그 갱신 전에 실패한다. 이 함수는 원본 미제공 상태이므로 실제 연결에 호출하지 않았다.
- S1 재검토: 목표 이력 및 선택 저장, 복원 시 재평가·목표 좌표 캐시 초기화, 타일 변경 시 목표 후보 갱신, 까치의 현재 GuideTarget 공급 연결이 존재한다. 실제 까치 이동 검증은 사용자 보류 상태다.
- S3 재검토: 용기별 요구 온도, 충족 전환 1회, 일일 처리 결과와 원인 우선순위, 패널 확인 이후 g09 완료, 미확인 결과 저장·복원 연결이 존재한다. 동일 실내 냉각 제한은 별도 최신 확정 문서를 따른다.

플레이어 낙하·착지는 사용자 요청에 따라 제외한다. 패키지 에디터용 화살표나 투사체/다른 아이템 그림을 목표 화살표로 대체하지 않는다.

## 검증

- CPU C# 컴파일: 런타임 오류 0/경고 3, 에디터 오류 0/경고 38.
- Unity MCP: 비플레이·컴파일 종료·콘솔 오류 0건, 카탈로그의 4종 미연결 재조회. 화살표 Sprite 검색 결과는 보급대/투사체 및 패키지 에디터 리소스뿐이었다.
- 기존 S2/S3 사용자 플레이 확인은 보존한다. 이번 서리 파동·실내 냉각 제한 및 까치 안내는 에이전트 런타임 검증 완료로 표현하지 않는다.
- 전체 완료 조건: 위 원본 연결, 화살표 지시 방향 및 4종 실제 표시 확인, 까치 안내와 같은 실내 냉각 추가 플레이 확인.
