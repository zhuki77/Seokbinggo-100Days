# 밀폐 코어의 같은 실내 냉각 규칙

2026-10-05 사용자 전달 기획자 확정: 밀폐 코어의 냉각은 코어와 같은 실내 영역에만 적용한다.

- 밀폐 코어: 기존 사각형 냉각 사거리 안이면서 코어의 밀폐 실내 공기 영역에 포함되어야 냉각한다. 닫힌 문·벽을 사이에 둔 외부나 별개의 방은 냉각하지 않는다.
- 기존 자연 온도와 미밀폐 코어의 약한 냉각 규칙은 유지한다. 다른 코어가 있는 경우 각 코어의 적용 조건을 독립적으로 판정하여 합산한다.
- SealSystem의 코어 리전 interiorAirCells를 재사용한다. 타일·문 변경 시 기존 캐시 무효화 경로가 반영되며 온도 조회마다 새 Flood Fill을 추가하지 않는다.
- RoomTempService.ResolveExact, InspectStorageEnvironment, InspectShelter가 동일한 적용 조건을 사용한다. 플레이어 온도, 장독 보관 온도·일일 부패/해빙 및 보관 조건 안내가 해당 경로를 사용한다.
- 실내에 있더라도 기존 코어 사거리 밖이면 냉각하지 않는다. 자연적으로 추운 외부는 코어 냉각이 없어도 낮은 온도를 유지할 수 있다.

## 검증

- 정적 코드 흐름 검토: 같은 방·사거리 안은 밀폐 냉각, 벽 너머 외부·별도 방은 해당 밀폐 코어 냉각 0, 같은 방·사거리 밖은 냉각 0, 미밀폐 코어는 기존 사거리 냉각.
- CPU C# 컴파일: 런타임·에디터 오류 각 0개. Unity MCP 콘솔 오류 조회 0건.
- Unity/게임 실행·런타임 검증은 수행하지 않았다.
