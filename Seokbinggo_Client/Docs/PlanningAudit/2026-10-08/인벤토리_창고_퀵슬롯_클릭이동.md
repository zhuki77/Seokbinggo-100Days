# 인벤토리·창고·퀵슬롯 클릭 이동

## 구현
- 인벤토리, 장독창고 양쪽 그리드, 퀵슬롯에 같은 클릭 처리를 사용한다. 같은 그리드를 쓰는 자연 상자에도 적용한다.
- 빈손 좌클릭: 스택 전체 집기. 빈손 우클릭: 절반 집기(홀수는 올림).
- 든 상태 좌클릭: 전체 놓기, 같은 ID 합치기, 다른 ID와 교환.
- 든 상태 우클릭: 빈 칸/같은 ID에 1개 놓기. 다른 ID에는 놓지 않는다.
- 최대 스택을 초과한 수량은 손에 남으며 MaxStack=1 장비는 합치지 않는다.
- 퀵슬롯 클릭도 같은 규칙을 사용한다. 플레이 중 퀵슬롯 선택은 숫자키/휠을 사용한다.
- 인벤토리·창고를 열어도 퀵슬롯을 표시한다. 커서 아이콘은 입력을 가로채지 않는다.
- 기존 인벤토리 슬롯 우클릭 사용을 제거했다. 선택한 아이템 사용/설치는 E 또는 해당 버튼을 사용한다.
- 손에 든 동안 월드 공격·설치 입력을 차단한다. 창 닫기 시 원래 보관함과 슬롯에 반환한다. 손에 든 상태의 ESC는 반환만 처리하고 창은 유지한다. 빈손 ESC는 창을 닫는다.
- 손에 든 스택은 독립적인 1슬롯 인벤토리에 실제 보관하고 저장/복원한다. 구 저장에는 빈손으로 적용한다.
- 분할할 때 누적 용해 소수량을 수량 비율로 나누고, 합칠 때 더한다. 합산 소수량이 1개 이상이면 해당 정수 용해량을 반영한다. 보관 상태(신선도 적용 여부, 신선도, 누적 용해량)가 다른 같은 ID는 합치지 않는다.
- 양쪽 인벤토리 수정이 끝난 뒤 변경 이벤트를 발행한다.

## 직접 플레이 확인
1. 나무 9개를 우클릭: 슬롯 4개, 손 5개. 빈 칸에 우클릭 두 번: 그 칸 2개, 손 3개. 좌클릭으로 나머지 모두 놓는다.
2. 같은 아이템 스택을 좌클릭으로 합친다. 최대 스택 가까이 채운 칸에 놓아 초과분이 손에 남는지 확인한다.
3. 다른 종류에 좌클릭하면 교환되고 우클릭하면 변하지 않는지 확인한다. 같은 무기 두 개는 합쳐지지 않아야 한다.
4. 인벤토리→퀵슬롯→창고→인벤토리를 오가며 위 조작을 반복한다. 인벤토리를 닫은 상태의 퀵슬롯 클릭도 확인한다.
5. 창고에서 전체/절반을 집고 ESC: 원래 창고 슬롯으로 돌아가고 창은 유지되어야 한다. 다시 ESC: 창이 닫혀야 한다. 인벤토리에서 집은 경우에는 원래 인벤토리 슬롯으로 돌아가야 한다. 닫기 버튼/E로 창고를 닫는 경우에도 원래 슬롯으로 반환되어야 한다.
6. 손에 든 상태로 자동 저장 또는 타이틀 이동 후 이어하기: 슬롯과 손의 합계가 보존되고 커서에 든 스택이 복원되어야 한다.
7. 보관 상태가 다른 같은 아이템은 좌/우클릭 모두 합쳐지지 않아야 한다. 같은 상태의 아이템은 기존대로 합쳐져야 한다.
8. 인벤토리 슬롯 우클릭이 아이템 사용/설치를 동시에 실행하지 않는지, 손에 든 상태의 월드 클릭이 공격/설치로 새지 않는지 확인한다. 숫자키·휠 선택과 E/버튼 사용도 확인한다.

## 검증 범위
- CPU C# 컴파일 및 코드 흐름 정적 검토만 수행했다.
- 회귀 검증 코드는 기존 Editor 소스에 추가했으며 실행하지 않았다.
- Unity/게임 실행, Play Mode 및 GPU 검증은 수행하지 않았다.

## Shift 즉시 이동 추가
- 장독창고를 연 상태에서 양쪽 슬롯 또는 퀵슬롯의 Shift+좌클릭은 전체, Shift+우클릭은 절반(홀수 올림)을 상대 인벤토리로 즉시 옮긴다.
- 이미 손에 든 아이템은 유지한다. Shift 이동은 손에 새로 집지 않는다.
- 같은 ID라도 보관 상태가 다르면 별도 빈 칸에 놓는다. 필요한 공간이 부족하면 원본 수량은 그대로 유지한다.
- 확인: 9개를 Shift+우클릭하면 반대편 5개/원래 칸 4개, Shift+좌클릭하면 나머지 4개 이동. 양방향, 좌/우 Shift 및 창고 열린 상태의 퀵슬롯에서도 반복한다.
- 확인: 다른 신선도 스택만 있는 가득 찬 창고로 Shift 이동하면 실패하며 양쪽 수량이 변하지 않아야 한다. 빈 칸이 생기면 별도 스택으로 이동해야 한다.

## 커서 원위치 반환
- 집기 또는 다른 ID 교환으로 새 아이템을 들 때 원래 보관함 ID/슬롯과 남은 스택을 기록하고 함께 저장한다.
- 일부를 다른 칸에 놓았다면 손에 남은 수량만 반환한다. 이미 놓은 아이템은 이동 취소하지 않는다.
- 원래 칸이 바뀌었다면 덮어쓰지 않고 같은 보관함의 합칠 수 있는 칸/빈 칸으로 반환한다. 공간이 없으면 손에 보존하고 닫기를 막는다.
- 원래 창고가 파괴되어 사라진 예외에만 플레이어 인벤토리로 반환한다.
- 확인: 전체/홀수 절반 집기, 1개 놓기 후 ESC, 창고 닫기, 탭 전환, 저장/이어하기 후 ESC를 인벤토리·창고·퀵슬롯에서 반복한다. 이미 놓은 수량+원래 칸 수량의 합계가 보존되어야 한다.

## WASD와 커서 보유 중 이동
- 인벤토리 Gathering 탭의 W/A/S/D 슬롯 탐색을 제거했다. 방향키 슬롯 탐색과 다른 탭의 기존 조작은 유지한다.
- 창이 닫힌 상태에서 퀵슬롯 아이템을 집어도 좌우 이동·점프·밧줄 조작은 유지한다. 창 자체가 열린 동안의 이동 차단은 유지한다.
- 손에 든 아이템을 옮기는 클릭이 월드 공격·채굴·설치로 이어지지 않도록 해당 입력 차단은 유지한다.
- 확인: 인벤토리를 열고 WASD를 눌러 선택 슬롯이 바뀌지 않는지 확인한다. 창을 닫고 퀵슬롯에서 집은 뒤 이동·점프·밧줄 조작하고, 다른 슬롯에 놓기와 ESC 반환도 확인한다.
