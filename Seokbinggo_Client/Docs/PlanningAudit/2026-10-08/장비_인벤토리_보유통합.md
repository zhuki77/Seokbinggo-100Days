# 장비 보유와 인벤토리 통합

- 방어구·장신구·장착한 무기/도구를 인벤토리의 실제 아이템으로 유지한다. 장비창은 같은 아이템의 보유·장착 상태를 참조한다.
- 처음 획득한 장비를 인벤토리에서 제거하는 승격 처리를 제거했다. 장착/해제 시 실제 아이템을 추가하거나 빼지 않는다.
- 장독창고/자연 상자로 이동한 비장착 장비는 장비창 보유 목록에서 빠지고, 다시 인벤토리로 꺼내면 다시 표시된다. 커서에 든 동안에는 보유 목록에 유지한다.
- 장착 중인 ID는 창고로 클릭 놓기 및 Shift 즉시 이동을 거부하고 해제 안내를 표시한다. 같은 ID의 다른 복사본도 장착 중에는 창고 이동을 거부한다.
- 이전 저장은 별도 보유 장비 목록과 활성 장비를 실제 아이템으로 한 번 옮긴다. 이전 인벤토리의 중복 획득분은 유지한다. 변경 후 저장에 마이그레이션 표시를 넣어 재로드 시 추가 생성하지 않는다.
- 이전 저장의 인벤토리가 가득 찼다면 기존 아이템 수령 대기 목록에 보존한다. 인벤토리에서 수령하면 실제 슬롯에 표시된다.
- 소모/절도 등으로 실제 보유 아이템이 모두 사라지면 남은 장착 참조를 해제한다. 저장 복원 중에는 임시 상태 때문에 해제하지 않는다.

## 플레이 확인
1. 이전 세이브를 이어서 인벤토리에서 기존 방어구·장신구·장착 무기까지 확인한다. 이미 중복 소유한 장비는 별도 슬롯에 남아야 한다.
2. 새 방어구를 처음 제작/획득하고 인벤토리와 장비창 양쪽에 나타나는지 확인한다.
3. 장착/해제를 반복해도 총 아이템 수가 바뀌면 안 된다. 무기 중복 획득도 각각 별도 슬롯이어야 한다.
4. 방어구·장신구·무기·등불을 각각 장착하고 창고에 클릭 놓기/Shift 좌클릭/Shift 우클릭을 시도한다. 경고가 나오며 창고에 들어가지 않아야 한다.
5. 장착 해제 후 창고로 옮기면 장비창 보유 목록에서도 사라져야 한다. 인벤토리로 꺼내면 다시 보여야 한다.
6. 변경 후 저장·타이틀·이어하기를 두 번 반복해 장비 수량이 늘지 않는지 확인한다.
7. 인벤토리가 가득 찬 이전 저장의 장비는 수령 대기 목록에 보존되는지, 공간을 비우고 수령 가능한지 확인한다.

## 검증
CPU C# 컴파일 및 정적 검토만 수행했다. 회귀 코드는 작성했지만 실행하지 않았다. Unity/게임 실행 및 GPU 검증은 하지 않았다.
