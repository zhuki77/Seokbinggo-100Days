# 제작 목표 화살표 전환

## 적용
- 단일 제작물의 설치/소유/수량 목표: 작업대, 화로, 철 주괴 2개, 얼음 저장고, 무쇠 발톱, 얼음 모루, 얼음강철 발톱.
- 현재 레시피와 플레이어 인벤토리를 읽어 부족한 재료를 결정한다. 여러 재료가 부족하면 레시피 순서의 첫 부족 재료부터 안내한다.
- 목표 수량에 필요한 제작 횟수를 반영한다. 재료가 가공품이면 해당 레시피/제련 재료로 재귀적으로 내려간다. 제련은 원료와 연료를 함께 확인한다.
- 재료가 충분하면 해당 제작대의 가장 가까운 설치 위치로 전환한다. 제작대 자체가 없으면 제작대 제작 준비를 안내한다.
- 손 제작이 가능한 상태에는 월드 화살표를 숨긴다. 완성된 설치물이 인벤토리에 있으면 추가 재료 수집을 안내하지 않고 화살표를 숨긴다.
- 일반 광맥은 TileService의 실제 셀 중심 좌표를 사용한다. 나무/삼줄기/철근은 아직 채집되지 않은 실제 장식 자원 위치를 사용한다.
- 밀폐, 보존, 휴식, 보스, 핵심 모듈 5종과 같은 복합 행동 목표는 기존 목표를 유지한다.
- 안내용 수량은 플레이어 인벤토리 기준이다. 창고 재료는 꺼내야 제작 재료로 반영된다.

## 직접 확인
1. 화로 목표에서 돌/흙/철/구리 중 일부가 부족한 상태를 만든다. 화살표는 첫 부족 재료를 가리킨다.
2. 화로 재료를 모두 마련한다. 화면 밖 작업대를 가리켜야 한다. 작업대가 화면 안이면 방향 화살표는 숨는다.
3. 구리 1개를 창고로 옮겨 부족하게 만들면 구리 광석으로 바뀌어야 한다. 다시 꺼내면 작업대로 바뀌어야 한다.
4. 철 주괴 2개 목표에서 광석은 충분하고 석탄이 부족하면 석탄을 가리킨다. 원료와 연료가 모두 충분하면 화로를 가리킨다.
5. 얼음 저장고, 무쇠 발톱, 얼음 모루, 얼음강철 발톱 목표에서도 부족한 재료 확보 전후를 비교한다. 충분해지면 각각 화로/화로/용광로/얼음 모루를 가리킨다.
6. 목표 설치물을 제작해 인벤토리에 가진 상태에는 광맥으로 재안내하지 않아야 한다. 설치하고 다음 목표로 정상 진행되는지 확인한다.
7. 작업대 목표에서 재료가 충분하면 화살표가 숨고 손 제작이 가능해야 한다.

## 검증
CPU C# 컴파일과 코드 흐름 정적 검토만 수행했다. Editor 회귀 코드는 추가했지만 실행하지 않았다. Unity/게임 실행 및 GPU 검증은 하지 않았다.
