# 정규 침공 코어 목표 거리 제한 해제

## 사용자 확정
- 정규 침공 밤에는 코어가 28타일 밖에 있어도 목표로 선정하고 접근한다.
- 일반 밤에는 기존 28타일 제한을 유지한다.
- 코어 목표 완료 후에는 완료한 코어를 제외하고 현재 요괴 위치에서 가장 가까운 코어를 선정한다. 일반 밤에는 28타일 이내 후보가 없으면 서성거리며, 정규 침공 밤에는 거리 제한 없이 다음 코어로 향한다.
- 다음 코어를 시작할 때 침투 기록 플래그를 초기화해 각 코어 도달마다 열기를 한 번 적용한다. 일반 밤의 열기 비적용 규칙은 유지한다.

## 구현
- InvasionService.IsCurrentInvasionNight를 일정 판정의 단일 출처로 사용한다.
- 정규 침공 밤의 Raid 스폰 트랙 요괴는 가장 가까운 현존 코어를 거리·밀폐 여부와 관계없이 선정한다. Resident 트랙에는 적용하지 않는다.
- 백중날 웨이브를 구분하는 raid 플래그로 정규 침공 여부를 판정하지 않는다.
- 코어가 없으면 기존 플레이어 목표/인식 흐름으로 돌아간다.
- 기존 저장의 Approach 상태에서 아직 인식하지 못했고 코어 목표/완료 이력이 없는 대기 개체는 이어하기 시 남은 코어를 선정한다. 전투 중인 개체, 절도 이후, 도주 및 완료한 코어 이력은 유지한다.
- 코어 도달 후 열기 적용, 다음 코어 선정, 최종 서성거리기는 기존 흐름을 사용한다.
- 실제 세이브 파일은 수정하지 않는다.

## 확인 범위
- CPU 기반 런타임 및 에디터 C# 컴파일과 정적 흐름 검토.
- Unity/게임 실행 및 GPU 검증은 하지 않는다.
- 플레이 확인: 현재 16일차 밤 저장을 이어하면 대기 중인 네 요괴가 멀리 있는 코어로 접근하는지 확인한다. 일반 밤의 반경 밖 개체는 기존 인식 대기를 유지한다.
