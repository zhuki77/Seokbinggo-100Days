# 장비창 원거리 탄약 수 표시

- 무기·도구 장착 슬롯의 아이콘 우측 하단에 작은 숫자를 겹쳐 표시한다. 인벤토리 수량 라벨의 글꼴·굵기를 공유하며 크기 8, 흰색, 외곽선 없음으로 통일한다. 우측 하단 앵커, 안쪽 여백 1, 입력 차단 없음.
- BowCombatRules.IsBowWeaponId와 AmmoItemId를 사용해 실제 발사 로직과 동일한 원거리 6종/돌을 판정한다.
- PlayerInventory 전체의 돌 수량을 합산한다. 0도 표시하며 근접/부채/등불/빈 슬롯은 숨긴다.
- 기존 PlayerInventory.Changed, ActiveSlot.Changed의 Refresh 흐름을 재사용한다. 장비창이 닫혀 있는 동안 변한 수량도 열 때 갱신한다.
- 기존 런타임 UI 생성 단계에서 라벨만 추가하므로 씬 직렬화 배선 변경은 없다.
- CPU 기반 런타임 및 에디터 C# 컴파일 오류 0개, Unity MCP 콘솔 오류 0개. 게임 실행/Play Mode/GPU 검증은 하지 않았다.
- 플레이 확인: 원거리 장착 후 장비창 숫자 확인 → 발사/돌 획득 후 다시 열어 수량 확인 → 돌 0일 때 0 표시 확인 → 근접 장비로 교체해 숫자 숨김 확인.
