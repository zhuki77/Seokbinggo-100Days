# v86 S6 재료 획득처 추적

2026-10-07. 정본: v86 안내시스템 S6 및 개발 B B7. 새 데이터 없이 현재 카탈로그의 광물·드롭·제작·제련·작물 정보를 이어서 표시한다. 강철이/이무기 이름은 사용자가 확정한 역할 정정을 따른다.

## 연결

- 제작과 제련 상세 영역 위에 부족한 재료의 이름 버튼을 표시한다. 재료를 누르면 상세 설명이 획득처로 전환되고, 다시 누르면 제작 설명으로 돌아온다. 재료별 수량을 합산해 부족 여부를 판단한다. 부족하지 않은 재료는 버튼을 표시하지 않는다.
- 원래 제작 목록과 실행 버튼을 유지한다. 출처 확인 클릭으로 제작·재료 지급·보상 지급을 실행하지 않는다. 다른 제작법으로 이동하거나 재료가 충분해지면 출처 선택을 해제한다.
- 기존 상세 ScrollRect를 재사용하고 상단 26픽셀을 재료 버튼 행으로 확보했다. 수가 많은 출처는 상세 영역에서 세로 스크롤한다. 버튼은 재사용하고 획득처는 선택 시 계산해 매 프레임 카탈로그 전체를 다시 검색하지 않는다.
- MaterialSourceGuide는 mineral-tiers, drops의 기존 임포트 결과(Yokai/Boss 정의), crafting-tree, smelting, crops, zones/terrain-spawn 카탈로그를 역검색한다. 별도 출처 CSV나 재료별 하드코딩은 없다.
- 광물: 지층/지상, 깊이, 필요 발톱과 경도. 철 광석의 소프트 게이트는 T1로 표시한다.
- 요괴: 이름, 밤/상주, 확정 또는 기본 확률과 매번 나오지 않음. 야광귀 보따리는 절도 성공 후 처치 조건을 함께 표시한다. 기본 확률이므로 특성 등의 확률 보정값과 구분된다.
- 보스: 데이터의 현재 이름과 격파 시 확정 드롭. 여의주 출처는 강철이다.
- 제작/제련: 설비 및 재료 수량, 제련은 연료도 표시한다. 현재 숨김 정책에 맞춰 B 제작법은 출처에 노출하지 않는다.
- 작물: 밴드와 거점 기준 거리, 해당 작물의 지형 리소스 등록이 있을 때 지형을 추가한다. 미구현 지형은 제외하고 같은 지형 이름은 중복 제거한다. 획득처가 없으면 등록되지 않았다고 표시하며 임의 장소를 만들지 않는다.

## 영역과 검증

데이터 조회(Data/MaterialSourceGuide), 제작 UI(MainGameCraftingUiController)만 제품 기능을 연결했다. 저장 구조, 드롭 수치, 제작 비용/해금은 변경하지 않았다. 기존 작업분을 보존했다.

- 실제 MaterialSourceGuide.cs를 연결한 독립 CPU 검사 19/19 통과. Unity 비의존 대체 타입을 사용하며 채집/경도, 확률/확정/절도 조건, 밤/상주, 복수 출처, 제련/연료, 제작/B 제외, 작물/지형 중복, 미등록 출처를 검사했다.
- 현재 CSV와 임포트된 SO의 광물 깊이/발톱/경도, 요괴 확률/조건, 작물 밴드/스폰 수치 106/106 일치 확인.
- 실제 카탈로그를 읽는 Editor 회귀 항목도 추가했다. 사용자 지시에 따라 실행하지 않고 C# 컴파일만 확인한다.
- 런타임·에디터 C# 컴파일 오류 0개. Unity/게임/Play Mode/GPU 실행과 화면 검증은 하지 않았다. Unity MCP로 읽은 콘솔에는 기존 guideDay 0→1 저장 왕복 불일치 오류가 남아 있다.

CPU 재실행: `dotnet run --project Docs/PlanningAudit/2026-10-07/S6CpuChecks/S6CpuChecks.csproj --no-restore`.

## 실제 플레이 확인

재료를 충분히 가지고 있으면 선택 버튼이 없으므로, 해당 재료가 부족한 제작법을 선택한다.

1. 화로 제작법에서 부족한 철 광석 선택 → 채집, 지하 중층, 깊이 46~90칸, 필요 발톱 T1/경도 1. 구리 광석도 자신의 데이터와 구분되는지 확인한다.
2. 도깨비 방망이 또는 씨름 샅바 제작법에서 부족한 방망이 조각 선택 → 방망이 도깨비, 밤, 기본 확률 25%, 매번 나오지 않음. 몇 마리 처치하면 반드시 나온다는 표현이 없어야 한다.
3. 무쇠 발톱 또는 얼음 저장고 제작법에서 부족한 철 주괴 선택 → 화로 제련, 철 광석 2개와 석탄 1개가 표시되어야 한다.
4. 화로 제련 화면에서 부족한 원석/석탄 선택 → 각각의 채집 출처. 출처를 눌러도 제련을 시작하거나 재료를 소모하지 않아야 한다.
5. 같은 재료 버튼 재클릭 → 원래 설명 복귀. 다른 제작법으로 이동 → 이전 재료 출처가 남지 않아야 한다. 재료가 충분해지면 해당 버튼과 선택이 해제되어야 한다.
6. 길어진 출처 목록 스크롤, 재료 버튼/제작 버튼/상세 설명의 겹침·잘림을 확인한다. 가방·장독·장비·도감 화면에는 재료 출처 버튼이 남지 않아야 한다.
7. 여의주가 부족하고 빙정 냉각로 제작법을 선택할 수 있는 상태라면 여의주 출처가 강철이 격파 확정인지 확인한다.

현재 crafting-tree에는 캣닢을 소모하는 제작법이 없으므로 작물 밴드 안내는 일반 제작 화면에서 직접 확인할 수 없다. 작물 역검색은 CPU/카탈로그 회귀 대상으로 검증한다. 이를 위해 새 제작법을 추가하지 않았다.
