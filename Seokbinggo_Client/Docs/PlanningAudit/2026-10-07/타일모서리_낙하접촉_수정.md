# 타일 모서리 낙하 접촉 수정

2026-10-07. 플레이어·요괴가 지형 끝에서 낙하하지 못하는 보고에 따른 수정.

기존 플레이어 하향 Cast는 타일 충돌체 유무만 확인하여 벽 접촉도 착지로 판단할 수 있었다. 요괴는 발밑 중심 한 점의 논리 타일을 사용했다. 둘 다 벽 마찰 방지용 물리 재질이 없었다.

PlayerMovementPhysics.HasForegroundGroundSupport로 공통 처리한다. 실제 전경 접촉점이 발밑에 있고 법선 y>0.5인 경우만 지지로 인정한다. 근접 하향 Cast 역시 법선과 접촉 높이를 확인하고 트리거를 제외한다. 시작부터 겹친 Cast는 검사 반대 방향의 법선일 수 있어 거리 0 결과를 착지로 사용하지 않고 실제 접촉 목록으로 확인한다. 요괴의 이동 Cast 배열과 착지 배열을 분리해 서로 덮어쓰지 않게 했다.

플레이어·요괴 Collider에 공유 이동 재질(마찰 0, 반발 0)을 적용한다. 지형과 드롭템 재질·캐릭터 폭·중력·점프 설정은 유지한다. 벽 접촉이 수직 낙하를 마찰로 방해하지 않게 하는 목적이다.

검증: 런타임·Editor CPU C# 컴파일 오류 0개. Unity MCP API 시그니처 및 컴파일 오류 확인. 게임 실행·물리 시뮬레이션은 수행하지 않았다. 실제 플레이에서는 벽 쪽 이동키를 누른 낙하, 계단 끝 낙하, 평지 착지·점프, 요괴의 모서리 추격을 확인한다.
