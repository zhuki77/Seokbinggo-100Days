# 캣닢 지하 생성 제한

사용자 확정: 캣닢도 버섯처럼 지하에서는 동굴에 생성한다.

- 자연 배경, 열별 실제 지표와 CaveSurfaceCrustThickness를 이용해 지하 동굴을 판정한다. 버섯과 같은 4방 연결 공간 및 자연 고체 바닥/머리 공간 또는 동굴 끝 조건을 사용하며, 바닥 후보가 두 칸 미만인 고립 포켓은 제외한다.
- 이미 생성된 통과 가능한 버섯은 동굴 연결 판정에 포함하지만 캣닢을 겹쳐 놓지 않는다. 지상 후보와 직접 심기는 유지한다.
- 원래 시드 후보·난수 소비·패치 ID는 유지한다. 부적합한 자연 패치는 표시/상호작용에서 제외하므로 기존 채집·재생 기록이 다른 위치에 붙지 않는다. 제외분을 다른 위치로 다시 뽑지는 않아 표시 밀도가 줄 수 있다. 기존 저장도 재구축/이어하기 시 같은 필터를 적용한다. 지형·버섯 생성 및 저장 파일 자체는 변경하지 않는다.
- CPU 검사: 실제 BuildNaturalCatnipSites 메서드를 추출한 독립 검사에서 지상 유지, 고립 포켓 제외, 동굴 허용, 자연 배경 없음 제외, 표층 두께 적용, 버섯 연결/중첩 방지 6/6 통과. CatnipCpuChecks/Program.cs는 검사 당시 추출본이다.
- Unity/게임 실행 및 GPU 검증은 수행하지 않는다.
