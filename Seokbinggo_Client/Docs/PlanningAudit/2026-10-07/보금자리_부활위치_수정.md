# 보금자리 부활 위치 결함

2026-10-07 사용자 보고 및 수정. 현재 저장 0번은 8일차 밤이며 보금자리는 (299.5, 141.5), 그 아래 (299, 140)는 설치한 흙이다. Unity 콘솔에 목표 (299.5, 141.5)를 지표면 탐색으로 (299.5, 84.38)로 변경한 기록이 2회 있었다.

원인: ApplyRespawn이 보금자리 유무와 무관하게 ResolveSafeSurfaceRespawn을 호출했다. 이 경로는 X만 받아 열을 아래로 검색하며 설치한 바닥을 제외한다. 보금자리 높이를 버리고 지하 자연 지형 위를 선택할 수 있었다.

수정: 보금자리가 있으면 셀 바닥과 플레이어 콜라이더 크기/오프셋으로 서 있을 위치를 계산한다. 실제 비트리거 정적 충돌체로 몸 전체가 비어 있는지, 발아래 지지가 있는지 확인한다. 설치 바닥도 인정하고 배경·트리거·다른 동적 액터는 지형으로 보지 않는다. 막혔을 때는 좌우 3칸·상하 2칸 안에서 원래 자리와 가장 가까운 안전 위치를 선택한다. 모든 후보가 막혔으면 초기 스폰 위치로 돌아가고 경고를 남긴다. 보금자리가 없을 때만 기존 지표면 검색을 사용한다.

사망 중 플레이어 콜라이더는 꺼져 있으므로 bounds 대신 size/offset/lossyScale로 검사한다. 검사 전에 생존 시 회전을 복원한다. 저장 좌표나 지형 데이터는 변경하지 않았다.

검증: 런타임 및 Editor CPU C# 컴파일 오류 0개. Unity MCP 스크립트 오류 0개. 게임·Play Mode는 실행하지 않았고, 실제 부활 화면은 사용자 플레이에서 확인해야 한다.
