## 수정 근거와 검증

- 서로 다른 컴포넌트의 단축키를 GameplayInput.cs의 단일 표로 통합. F5 안내도 같은 표에서 생성한다.
- Ctrl/Shift/Alt의 정확한 조합만 처리하므로 추가 보조키가 눌린 경우 다른 기능이 대신 실행되지 않는다.
- 월드 테스트는 F5 안내·일시정지·제작/인벤토리 중 실행을 차단한다. 제작 테스트 F12/Shift+F12는 해당 창을 열어야 한다. 등탑 지급은 설치 미리보기를 먼저 취소한다.
- 보스 강제 소환은 기존 밤 조건을 유지하고 실패 이유를 안내 메시지로 표시한다. 지정한 보스 정의가 없으면 다른 보스를 임의로 소환하지 않는다.
- 31일 이후 테스트는 확장 항목으로 표시한다. 30일 기획 범위를 변경하지 않는다.
- 32개 동작·키 조합 중복 없음. 9개 키 × 8개 보조키 조합(72개) 정적 대조 및 각 동작의 처리 코드 1개 연결 확인.
- CPU C# 컴파일: 런타임 오류 0/경고 3, 에디터 오류 0/경고 38. 런타임 다음 에디터 순차 수행.
- 기존 회귀 검사의 키 기대값을 갱신했다. Unity 테스트 실행·게임 실행·키 입력 재생은 수행하지 않았다. 실제 단축키와 안내창 가독성은 플레이 확인 필요.
- 기존 아트·기획·로프 작업을 보존. 데이터·세이브 형식 변경 없음. 공유 플레이어/전투/UI 파일은 병합 시 겹치는 변경 확인 필요.

## 플레이 확인 순서

1. 새 컴파일 반영 후 F5에서 두 페이지가 보이며 모든 항목이 잘리지 않는지 확인한다. F5 또는 Esc로 닫는다.
2. Shift+F11로 로프 99개, F11로 아트 아이템을 받아 서로 중복 지급되지 않는지 확인한다.
3. F6 보스 선택 → Ctrl+F6 재료 → Ctrl+Shift+F6 제작대 이동 → Shift+F6 제작을 확인한다.
4. 밤에 F7/Shift+F7/Ctrl+F7을 각각 확인한다. 활성 보스가 있으면 Shift+F8로 처치한다. 낮에는 조건 안내가 나오는지 확인한다.
5. 제작·제련창에서 F12 재료 지급과 Shift+F12 제작대 이동을 확인한다. 장비창의 F12는 장비/도구 지급이다.
6. 인벤토리나 F5 안내를 연 채 F7/F9/F10을 눌러 월드 소환·연출이 실행되지 않는지 확인한다.
7. F10과 Shift+F10 연출, Ctrl+F10 등탑 지급이 각각 따로 실행되는지 확인한다.
