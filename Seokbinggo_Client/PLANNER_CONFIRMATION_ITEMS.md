# 기획자 확인 필요 항목

최신 기획 정본 `ExportBlock-26_07_21_18_42.zip`과 현재 구현을 대조했으나 확정 규칙을 찾지 못한 항목을 기록한다. 개발자가 임의로 사양을 확장하지 않고 기획 회신 후 반영한다.

## 1. 일반 제작 진행도와 다중 제작 정책

- 현재 구현은 일반 제작을 한 번에 1건만 진행하며, 화면 하단 타일 팔레트 위에 단일 진행 막대를 표시한다.
- 최신 기획에는 근처 제작대 필터, 제작 목록 정렬, 아이콘·수량, 재료 부족 표현만 있고 진행 막대의 위치·형태는 명시되어 있지 않다.
- 화로·용광로의 제련 대기열은 별도로 규정되어 있지만 일반 제작의 동시 제작 또는 대기열 규칙은 없다.
- 확인 요청:
  1. 일반 제작을 현재처럼 1건만 허용할지, 여러 건의 대기열을 허용할지
  2. 단일 또는 다중 제작 진행도를 어느 화면 영역에 어떤 형태로 표시할지
  3. 여러 건을 허용한다면 동시 진행인지 순차 대기열인지, 최대 개수와 취소·재료 반환 정책은 무엇인지

## 2. 복수 버전 아트 최종 선택

아트 전달 ZIP의 원본 파일과 현재 프로젝트 파일을 SHA-256으로 대조했다. 아래 항목은 복수 시안 중 어느 버전을 정본으로 사용할지 기획 확인이 필요하다. 회신 전까지는 현재 연결본을 유지한다.
